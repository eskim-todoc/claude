# 양식 — 이력 및 결과.md

**TL;DR**: 4단계 이력 및 결과 산출물 표준 양식. **단계 ① 시작과 동시에 생성** — 단계 진척 표 + 시계열 로그(진행 중 누적) + 완료 요약(종료 시 추가). 단계 전이·결정·이슈·차단 발생·해소마다 시계열 로그 갱신. 본 양식 본문을 작업 폴더의 `이력 및 결과.md`로 복사.

## 사용법

1. **단계 ① 시작과 동시에 생성** — 작업 폴더 만들고 `요구사항.md`를 시작할 때 본 파일도 함께
2. 본 파일의 §양식 본문을 복사해서 작업 폴더의 `이력 및 결과.md`로 저장
3. `<...>` placeholder 채움
4. **본문 섹션은 양식 §순서·헤더 그대로 사용** (해당 없는 섹션도 헤더 유지 + "해당 없음" 표기)
5. **상태 표시는 텍스트만** 사용 — `완료` / `진행` / `대기` / `차단`. **이모티콘(✅·❌·🔄 등) 혼용 금지** (양식 일관성)
6. 단계 진척 표: 단계 진입·종료마다 갱신
7. 시계열 로그: 결정·이슈·차단·해소·다음 동작 변경 시마다 한 줄 추가
8. 완료 요약: 작업 종료(`작업 끝났어. 마무리해` 시그널) 시 추가 ([`../완료처리.md`](../../일반/작업/완료처리.md))
9. 흡수된 구 `진행상황.md` 본문이 있다면 시계열 로그의 `<details>` 블록으로 보존 가능

> [!IMPORTANT]
> 양식은 **포괄적 골격**이다. 양식의 모든 §섹션 헤더는 기존 본문에 그대로 유지(순서·명명). 작업 특성상 해당 없는 섹션은 본문에 **"해당 없음"** 한 줄로 표기 — 헤더 자체를 삭제하지 않는다. 이렇게 해야 모든 작업이 동일한 인지 경로(LLM·사람 모두)로 읽힌다.

| 단계 | 산출물 | 상태 | 일시 |

**상태값** (텍스트만, 이모티콘 혼용 금지): `대기` → `진행` → `완료` (자체 검토 통과 후) 또는 `차단`(이슈 명시) 또는 `면제`(해당 없음 — 예: 분석 단계 산출물 없는 작업은 "면제" + 일시는 "—")
