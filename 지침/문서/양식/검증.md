# 양식 — 검증.md

**TL;DR**: 8단계의 검증 단계(②④⑥⑧) 공용 양식. 각 산출물 직후 자체 검증 3축(지침 준수·논리 정합·근거 검증) + 단계별 할루시네이션 방지 게이트 결과를 **독립 파일**로 남긴다. 이 양식을 `요구사항-검증.md`/`분석-검증.md`/`계획-검증.md`/`구현-검증.md`로 복사해 사용. 검증은 자체 검증 — 사용자 승인 게이트는 ⑥ 직후 1회뿐.

## 사용법

1. 각 산출 단계(①③⑤⑦) 작성·완료 **직후**, 본 파일의 §양식 본문을 복사해 `<단계>-검증.md`로 저장
2. `<...>` placeholder를 실제 검증 결과로 채움
3. 검증 3축 + 해당 단계 게이트([`작업-프로세스.md §3.4`](../../일반/작업/작업-프로세스.md)) 결과 기록
4. **판정**: 통과 / 이전 단계 회귀 / 사용자 질문. 회귀·질문이면 `이력 및 결과.md` 시계열 로그에 반영
5. 작성 직후 셀프 체크: frontmatter·TL;DR ([`../../문서/메타-frontmatter.md`](../../문서/메타-frontmatter.md))

> [!IMPORTANT]
> 검증은 **자체 검증**(Claude가 스스로 점검)이다. 오케스트레이션으로 대규모 산출물을 검증할 때는 저술↔검증 노드를 분리해 adversarial-verify로 강화한다([`서브에이전트/오케스트레이션.md`](../../서브에이전트/오케스트레이션.md)).
