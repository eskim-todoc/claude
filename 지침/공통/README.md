# 공통 (여러 카테고리 공유 규칙)

**TL;DR**: 특정 카테고리(일반·Git·코딩·문서·서브에이전트·설정)에 속하지 않고 여러 지침이 공유하는 무주공산 규칙만 둔다. 현재 경로·참조 표기 1건.

| 파일 | 내용 |
|---|---|
| [경로·참조 표기.md](경로·참조%20표기.md) | 상대/절대경로·크로스 repo·URL 인코딩·과거 tasks 소급 금지 |

> [!IMPORTANT]
> **추가 조건 (그랩백 방지)**: 이 폴더에는 **2개 이상 카테고리에서 중복 확인됐고 자연스러운 소유 파일이 없는** 규칙만 추가한다. 소유 파일이 있는 중복(Git Identity→`Git/브랜치, 병합 규칙.md`, tdc_→`코딩/네이밍 컨벤션.md` 등)은 그 SSOT에 두고 링크로 참조하며, 여기로 옮기지 않는다.
