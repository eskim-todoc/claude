# 기억

**TL;DR**: **헌법·지침이 «규칙»이라면 여기는 «사실»이다.** 규칙 아래서 일하며 알게 된 것 - 은수님이 어떻게 일하시는지, 제품·시험·하드웨어가 실제로 어떤지 - 을 주제별 파일로 쌓고 갱신한다. **세션 시작 시 이 인덱스만 읽고, 관련될 때 본문을 연다.**

> [!IMPORTANT]
> **세션 시작 시 이 파일을 Read 한다.** 인덱스만 보면 되고, 지금 하는 일과 관련된 줄이 있을 때만 본문 파일을 연다.
>
> **기억을 쓰거나 고칠 때는 [`운영 규약.md`](운영%20규약.md) 를 먼저 읽는다.** 쓸 때만 필요하므로 여기 싣지 않는다.

## 무엇이 여기 오고 무엇이 안 오는가

| | 어디로 | 왜 |
|---|---|---|
| **규칙·절차** ("이렇게 해라") | `지침/` | 규칙과 사실이 섞이면 둘 다 못 믿는다 |
| **사실** ("실제로 이렇다") | **여기** | |
| 작업 산출물 (요구사항·분석·계획) | 각 repo `docs/tasks/` | 시점에 묶인 기록 |
| 세션 경계 요약 | 각 repo `docs/세션_인수인계/` | 시계열이라 최신 1건만 읽는다 |
| 잊으면 안 되는 미결 | 각 repo `docs/상시 점검 대장.md` | «상태»지 «사실»이 아니다 |
| 코드·git 이 이미 말해 주는 것 | 아무 데도 | 적으면 drift 만 생긴다 |
