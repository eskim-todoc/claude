# 필수성능시험 (Sound1)

**TL;DR**: **정형화된 기준이 없어 기준서를 우리가 직접 만드는 시험**이다. 우리 제품에 대한 기준을 우리가 세우고, **외부 시험소 참관하에** 시험한 뒤 보고서를 받는다. 선행 사례로 Sullivan 1.5 의 EPTR-TD23D 보고서가 있고, **그 마이크 항목이 Sound1 에 그대로 적용 가능하다는 판정까지 나와 있다.**

## 1. 이 시험의 구조 - 다른 시험과 다르다

> 은수님 설명 (2026-08-18): *"이 시험은 기준서도 내가 만드는 시험이야. 정형화된 기준이 없기 때문에, 우리 제품에 대한 기준을 우리가 만들고, 외부 시험소 참관하에 시험 후 보고서를 받는 구조야."*

| # | 단계 | 주체 |
|---|---|---|
| 1 | **기준서 작성** - 무엇을 «필수 성능»으로 볼지, 어떤 값을 합격으로 볼지 정의 | **은수님(제조사)** |
| 2 | 시험 수행 | 제조사, **외부 시험소 참관하** |
| 3 | 보고서 수령 | 외부 시험소 |

> [!IMPORTANT]
> **합격선을 우리가 정한다는 것이 이 시험의 핵심이자 부담이다.** 규격이 답을 주지 않으므로 «왜 이 값이 합격선인가»를 기준서가 스스로 설명해야 한다. IEC 60601-1 은 «필수 성능(essential performance)» 을 정의만 하고, 무엇이 그에 해당하는지는 제조사가 정하도록 남겨 둔다. **확신도: 확인됨(은수님 설명) + 추정(IEC 조항 자체는 미확인)**

## 2. 선행 사례 - EPTR-TD23D 보고서

**위치**: `projects/sound1-fw-e8300/docs/참고/인허가 관련/EPTR-TD23D 필수성능시험 보고서_최종_251208.pdf` (42쪽, 커밋됨)

**Sullivan 1.5 에서 쓴 마이크를 기준으로 작성**된 보고서다. §5 «필수 성능 시험 항목» 부터가 본체다.

| 시험 ID | 무엇을 보는가 | 마이크 의존 |
|---|---|---|
| **ID-1 · ID-2** | **실제 소리 입력에 대한 ADC 값** | **있음** |
| ID-3 · ID-4 · ID-5 | **자극 펄스를 오실로스코프로 측정** | 없음 |
| ID-6 이후 | *"ADC 값 기준으로 13~16 이 되도록 설정한다"* 식 - 그 값이 나오는 소리 크기로 조정해 시험 | 없음 |

> [!CAUTION]
> **은수님이 처음 «ID-1~5 가 마이크 의존»이라 하셨는데 실제로는 ID-1·ID-2 둘뿐이다.** ID-3/4/5 는 오실로스코프로 자극 펄스를 본다. 제가 전제를 확인 없이 받아 적었다가 정정한 건이다

## 3. Sound1 적용 판정 - 이미 끝나 있다

**결론: 마이크가 달라도 ADC 표를 그대로 쓸 수 있다.** 상세 근거는 `projects/sound1-fw-e8300/docs/참고/오디오 입력 체인/09_필수성능시험 보고서를 Sound1에 쓸 수 있나.md`.

| 항목 | 판정 |
|---|---|
| 두 마이크 감도 | 동일 (−26 dBFS @ 94 dB SPL). **눈금이 같으므로 같은 음압 → 같은 코드** |
| 교차 검증 | 보고서의 **ADC 값 29건이 제 독립 분석과 전부 일치**했다. 체인 해석이 맞다는 상호 확인 |
| **ID-2 만 조건부** | **7990 Hz 를 쓴다. 고주파라 지향성이 생겨 빔 축을 ~30 도 안으로 맞춰야 한다** |
