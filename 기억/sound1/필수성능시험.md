# 필수성능시험 (Sound1)

**TL;DR**: **정형화된 기준이 없어 기준서를 우리가 직접 만드는 시험**이다. 우리가 기준을 세우고 **외부 시험소 참관하에** 시험한 뒤 보고서를 받는다. **지금의 과제는 Sound1 기준서 작성**이고, **선례가 생각보다 얇다** - 1.5세대 기준서는 설리번 것을 가져다 쓴 수준이었다. 다만 **마이크가 동일**해 핵심 수치는 이어받을 수 있다는 판정이 이미 나와 있다.

## 1. 이 시험의 구조 - 다른 시험과 다르다

> 은수님 설명 (2026-08-18): *"이 시험은 기준서도 내가 만드는 시험이야. 정형화된 기준이 없기 때문에, 우리 제품에 대한 기준을 우리가 만들고, 외부 시험소 참관하에 시험 후 보고서를 받는 구조야."*

| # | 단계 | 주체 |
|---|---|---|
| 1 | **기준서 작성** - 무엇을 «필수 성능»으로 볼지, 어떤 값을 합격으로 볼지 정의 | **은수님(제조사)** |
| 2 | 시험 수행 | 제조사, **외부 시험소 참관하** |
| 3 | 보고서 수령 | 외부 시험소 |

> [!IMPORTANT]
> **합격선을 우리가 정한다는 것이 이 시험의 핵심이자 부담이다.** 규격이 답을 주지 않으므로 «왜 이 값이 합격선인가»를 기준서가 스스로 설명해야 한다. IEC 60601-1 은 «필수 성능(essential performance)» 을 정의만 하고 무엇이 그에 해당하는지는 제조사가 정하도록 남긴다. **확신도: 확인됨(은수님 설명) / 추정(IEC 조항 원문은 미확인)**

## 2. 선례 계보 - 「선례가 있다」를 과신하면 안 된다

> 은수님 (2026-08-18): *"1.5세대에서도 기준서를 작성하고 시험 및 보고서 수령도 하긴했는데, 이때 기준서는 설리번을 기반으로 했었어. 그래서 사실 나도 직접 썼다기 보다는 그냥 가져다 쓴 정도야."*

```
설리번 기준서 (Ezairo 7150 세대)
   └─ 차용 ─> 1.5세대 기준서 ─> 시험·참관 ─> EPTR-TD23D 보고서 (2025-12-08)
                                                    └─ 차용? ─> Sound1 기준서  ← 지금 여기
```

| 판정 | 내용 |
|---|---|
| **항목 구성은 설리번에서 왔다** | 두 세대를 건너 내려온 것이라 **«왜 이 항목인가»가 재검토된 적이 없을 수 있다.** 확신도: 확인됨(은수님 진술) |
| **측정값은 8300 세대 것이다** | 보고서의 ADC 값 29건이 제 Sound1 체인 분석과 전부 일치했다. **적어도 숫자는 7150 시절 유물이 아니다** |
| **합격 임계의 근거는 미확인** | 임계값이 1.5세대에서 재도출된 것인지, 설리번에서 그대로 넘어온 것인지 **모른다.** Sound1 기준서를 쓸 때 **의식적으로 결정해야 할 지점** |

> [!CAUTION]
> **은수님이 «직접 썼다기보다 가져다 쓴 정도»라고 하셨다는 것은, 선례 문서에 담긴 판단 근거를 우리가 갖고 있지 않다는 뜻이다.** Sound1 기준서에서 *"1.5세대와 동일"* 이라고 쓰려면, **동일하다는 사실**과 **그 값이 왜 합격선인가**는 별개로 서 있어야 한다.

## 3. 선행 자료 - EPTR-TD23D 보고서

**위치**: `projects/sound1-fw-e8300/docs/참고/인허가 관련/EPTR-TD23D 필수성능시험 보고서_최종_251208.pdf` (42쪽, 커밋됨). **1.5세대에서 쓴 마이크 기준**으로 작성됐고, **§5 «필수 성능 시험 항목»** 부터가 본체다.

| 시험 ID | 무엇을 보는가 | 마이크 의존 |
|---|---|---|
| **ID-1 · ID-2** | **실제 소리 입력에 대한 ADC 값** | **있음** |
| ID-3 · ID-4 · ID-5 | **자극 펄스를 오실로스코프로 측정** | 없음 |
| ID-6 이후 | *"ADC 값 기준으로 13~16 이 되도록 설정한다"* 식 - 그 값이 나오는 소리 크기로 조정해 시험 | 없음 |

> [!CAUTION]
> **은수님이 처음 «ID-1~5 가 마이크 의존»이라 하셨는데 실제로는 ID-1·ID-2 둘뿐이다.** ID-3/4/5 는 오실로스코프로 자극 펄스를 본다. 제가 전제를 확인 없이 받아 적었다가 정정한 건이다.

## 4. Sound1 적용 판정 - 이미 끝나 있다

**결론: 마이크 눈금이 같으므로 ADC 표를 그대로 쓸 수 있다.** 상세 근거는 `projects/sound1-fw-e8300/docs/참고/오디오 입력 체인/09_필수성능시험 보고서를 Sound1에 쓸 수 있나.md`.

| 항목 | 판정 |
|---|---|
| 두 마이크 감도 | **동일** (−26 dBFS @ 94 dB SPL). 은수님도 *"마이크 성능도 동일하고 해서 큰 문제는 없을거라고 생각하는 중"* |
| 교차 검증 | 보고서 ADC 값 **29건이 독립 분석과 전부 일치**. 체인 해석이 맞다는 상호 확인 |
| **ID-2 만 조건부** | **7990 Hz 를 쓴다. 고주파라 지향성이 생겨 빔 축을 ~30 도 안으로 맞춰야 한다** |
| **미확인 - 마이크 공유** | **EZ 와 QCC 가 마이크를 공유한다**(`lib_audio_in.h:22`, [인공와우 제품군.md](../인공와우%20제품군.md) §3.2). 1.5세대는 nRF 였다. **공유 상대가 마이크를 점유할 때 시험값이 흔들리는지 확인된 바 없다** |
