# 은수님

**TL;DR**: 헌법이 «어떻게 말할지»(존댓말·호칭·페르소나)를 규정한다면, 여기는 «무엇을 전제하고 말할지»다. **제 분석의 오류를 근거를 들어 정확히 짚으시고 실제로 두 번 다 맞으셨다** - 확신을 과장하면 안 된다. 문서는 나중에 다시 읽으실 것을 전제로 쓴다.

## 1. 근무·작업 환경

| 사실 | 확신도 | 적용 |
|---|---|---|
| **원격 근무 중이라 실기(실제 장비 시험)가 불가하다.** 2026-08-05 지시 *"원격이라 실기가 불가능 해. 한번에 실기한다치고"* · *"실기는 그냥 나중에 몰아서 한번에 하는게 편할거 같아"* | 확인됨 | 실기가 필요한 변경도 **병합을 막지 않는다.** 대신 `projects/sound1-fw-e8300/docs/상시 점검 대장.md` §1 에 확인 항목을 쌓고 완료 보고마다 상기한다 |
| `rules` repo 는 **은수님이 직접 커밋·푸시**하신다 (*"루트 커밋/푸쉬는 따로 할게"*) | 확인됨 | 지침 문서를 고쳐도 커밋하지 않는다. **예외 - `기억/` 폴더는 커밋까지 Claude 가 하고 푸시만 남긴다**(2026-08-18 합의) |
| 장비 설정 파일은 미커밋으로 유지하신다 (`src/4__eeprom/nvmupdate.bat` J-Link 시리얼 등) | 확인됨 | 커밋·병합에 **절대 포함하지 않는다** |

## 2. 코드에 대한 배경 - 인수인계 받아 스터디하는 입장

> 본인 진술 (2026-08-13): *"자세한 이유를 몰라. 나도 인수인계 받아서 스터디하는 입장이거든."*

**Sound1 의 CFX(DSP) 쪽 - 오디오 체인·AGC·FFT·BFP - 은 전임자가 쓴 코드**이고 은수님이 넘겨받아 파악하시는 중이다. 반면 **cm3(ARM) 쪽과 BLE·자극 로직은 은수님이 직접 다루신다.**

| 적용 | |
|---|---|
| CFX 쪽 | **«왜 이렇게 되어 있는가»를 함께 설명한다.** 코드를 읽으면 안다는 전제를 두지 않는다 |
| cm3·BLE 쪽 | 구조를 이미 아신다. **결론과 근거만** 간결히 |

> [!NOTE]
> 그렇다고 CFX 를 모르시는 게 아니다. `>>5` 를 하신 이유를 **정확히 기억해 내셨고 제 설명이 틀렸음을 짚으셨다**(§3). 「인수인계 받았다」는 «출처를 다 되짚지는 못한다»는 뜻이지 «모른다»가 아니다.

## 3. 검증 성향 - 두 번 다 은수님이 맞으셨다

**제 분석을 그대로 받지 않으시고, 걸리는 부분을 구체적 근거로 되물으신다. 실제로 두 건 다 제가 틀렸다.**

| # | 제가 말한 것 | 은수님 지적 | 결과 |
|---|---|---|---|
| 1 | 믹서 `>>5` 는 과하니 `>>4` 로 줄이면 분해능이 2배 좋아진다 | *"볼륨 9, 10 에서 역으로 소리가 작아지는 현상이 있었다. 65535 가 최대여야 했다"* | **은수님이 맞았다.** 시뮬레이션 결과 `>>4` 는 볼륨 순서를 깨고 FFT 를 넘긴다. 제 문서 두 곳을 고쳤다 |
| 2 | 데시메이션 게인이 유니티에서 −5.17 dB 밀려 있다 | *"SDK `analog_in.h` 의 `Sys_Calc_Gain_Factor_Val()` 로 계산하면 1092 였던 거 같은데, 아닌가?"* | **은수님이 맞았다.** SDK 는 `floor(log2())` 를 쓴다. 데이터시트 인쇄식을 실수 `log2` 로 읽은 제 오독이었다 |

> [!CAUTION]
> **적용 - 확신도를 과장하지 않는다.** 근거가 코드면 «코드로 확인», 인쇄물이면 «문서로 확인», 유추면 «추정»이라고 **구분해서 쓴다.** 두 사고 모두 **인쇄된 문서를 구현보다 위에 둔 것**이 원인이었다.
>
> 여기서 나온 규칙: **데이터시트의 인쇄된 수식보다 SDK·펌웨어의 실제 구현이 우선이다.** 계산 함수가 SDK 에 있는지 먼저 찾는다.

| **범위를 넘겨 짚는 것을 싫어하신다.** 2026-08-18 *"먼저 앞서 나가지 말고, 지금은 내가 말하는 것에만 집중해봐."* | 새 작업 초입에 **스코프 질문을 여러 개 던지지 않는다.** 말씀하신 것만 처리하고 다음을 기다린다 |
