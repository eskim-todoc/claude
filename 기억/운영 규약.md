# 기억 운영 규약

**TL;DR**: **「기억해」 지시 또는 Claude 의 제안·승낙**으로 기록한다. 핵심은 **새 파일을 만드는 게 아니라 있던 파일을 고쳐 쓰는 것** - 그것이 «점진적 진화»의 실체다. 확신도를 승급하고, 틀렸던 것은 지우지 않고 남기고, 기록할 때마다 즉시 커밋한다.

## 1. 언제 기록하는가

| 경로 | 동작 |
|---|---|
| **은수님이 「기억해」** | 무조건 기록한다. 되묻지 않는다 |
| **Claude 판단** | 기록할 가치가 있다고 보면 **「이건 기억해둘까요?」라고 여쭙고, 승낙하실 때만** 기록한다. 임의로 만들지 않는다 |

**여쭐 가치가 있는 것**: 은수님이 제 분석을 정정하신 것 · 제품·시험·하드웨어의 확정된 사실 · 판단의 근거가 된 배경(왜 그렇게 결정했는가) · 다음에 같은 함정에 다시 빠질 만한 것.

## 2. 기록 절차 - 순서를 지킨다

| # | 할 일 |
|---|---|
| 1 | **[README.md](README.md) 인덱스에서 그 주제를 이미 다루는 파일이 있는지 본다** |
| 2 | **있으면 그 파일을 갱신한다.** 없을 때만 새로 만든다 |
| 3 | 본문을 고치고, **§갱신 이력에 한 줄** 추가한다 |
| 4 | README 인덱스의 «한 줄»과 «갱신» 날짜를 맞춘다 |
| 5 | **즉시 커밋한다** (푸시는 은수님) |

> [!CAUTION]
> **2번을 건너뛰면 이 폴더는 그냥 파일 더미가 된다.** 같은 주제로 파일이 둘 생기는 순간 어느 쪽이 맞는지 알 수 없게 되고, 그 시점부터 기억은 신뢰를 잃는다. **기억이 자란다는 것은 파일 수가 는다는 뜻이 아니라 파일이 정확해진다는 뜻이다.**

## 3. 진화 규약 셋

### 3.1 확신도를 표기하고 승급한다

| 표기 | 뜻 |
|---|---|
| **추정** | 정황·유추. 틀릴 수 있다 |
| **확인됨** | 코드·데이터시트·문서로 확인. 근거를 `파일:라인` 으로 남긴다 |
| **실측 확인** | 실기·계측으로 확인. 최상위 |

같은 사실이 더 강한 근거를 얻으면 **표기를 올리고 근거를 갈아 끼운다.**

> 실례 - 데시메이션 게인은 «추정(데이터시트 인쇄식으로 1979)» 이었다가 은수님 지적으로 «확인됨(SDK `Sys_Calc_Gain_Factor_Val()` 로 1092)» 이 됐다.

### 3.2 틀렸던 것을 지우지 않는다

**정정할 때 옛 내용을 삭제하지 말고 «이렇게 잘못 알았다 / 왜 틀렸다» 를 남긴다.** 지우면 같은 실수를 다시 한다. 남기면 그것 자체가 가장 값진 기억이 된다.

> 실례 - «데이터시트의 인쇄된 수식보다 SDK 구현이 우선» 이라는 규칙은, 틀린 기록을 남겨 뒀기 때문에 뽑아낼 수 있었다.

### 3.3 연결한다

관련 기억·문서를 **상대 경로 링크**로 잇는다. 하나를 읽으면 걸어갈 수 있어야 한다. 프로젝트 repo 문서를 가리킬 때는 어느 repo 인지 함께 적는다(`rules` 와 `projects/<name>` 은 형제 독립 repo라 상대 경로가 닿지 않는다).

## 4. 담지 않는 것

| 안 담는 것 | 이유 |
|---|---|
| 헌법·지침이 이미 규정한 규칙 | 두 곳에 있으면 반드시 어긋난다. **지침을 고쳐야 할 일이면 지침을 고친다** |
| 코드·git 이 이미 기록하는 것 | 구조 · 과거 수정 · 커밋 이력 |
| 이번 대화에서만 의미 있는 것 | 임시 경로 · 그때뿐인 수치 |
| 작업 산출물 · 시계열 요약 · 미결 상태 | 각각 `docs/tasks/` · `docs/세션_인수인계/` · `docs/상시 점검 대장.md` 가 주인이다 |

## 5. 파일 양식

```markdown
---
name: <주제>
purpose: <한 줄>
type: 기억
applies_to: [<범위>]
tags: [기억, ...]
---

# <주제>

**TL;DR**: 80~250자.

## <사실들>   ← 확신도 표기와 근거를 함께

## 갱신 이력
| 날짜 | 내용 |
|---|---|
```

파일이 커지면 쪼갠다. 쪼갤 때 **README 인덱스를 반드시 함께 고친다.**
