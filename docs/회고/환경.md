# 환경 회고

**TL;DR**: 설정·스크립트는 Project scope (`.claude/settings.json`) + git tracked. User scope·하드코딩 금지. 자격증명·로컬 전용은 `credentials/` 또는 `settings.local.json`.

설정·스크립트·훅의 환경 이식성 관련 학습.

## 환경 이식성 우선 (2026-04-21)

작업 산출물(설정 파일, 스크립트, 훅 등)은 어느 환경에서든 동일한 작업 상태를 유지할 수 있도록 설계.

**Why:** 사용자가 여러 PC/환경을 오가며 작업하며, `E:\Claude` 폴더를 복제해서 동일한 컨텍스트를 가져가는 워크플로우를 씀. `CLAUDE.md` 첫 줄에도 *"이 폴더를 복제하면 다른 환경에서도 컨텍스트 유지 가능"*으로 명시.

**How to apply:**
- Claude Code 설정은 User scope(`~/.claude/settings.json`)가 아니라 Project scope(`E:/Claude/.claude/settings.json`)에 둬서 git 추적 대상으로 만든다
- 공용 스크립트는 `E:/Claude/tools/`에 둔다
- 경로는 하드코딩하지 말고 `$CLAUDE_PROJECT_DIR` 환경변수를 사용한다
- 자격증명·로컬 전용 값만 `.claude/settings.local.json`이나 `credentials/`에 둔다
- 플랫폼 종속 스크립트(PowerShell 등)라도 경로만 이식 가능하면 일단 Project scope에 두고, 이식성 한계는 주석이나 docs에 명시
