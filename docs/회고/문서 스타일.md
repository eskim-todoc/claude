# 문서 스타일 회고

Markdown 문법, 다이어그램, 시각적 강조 관련 학습.

## GFM + Mermaid + Alert Blocks 문서 스타일 (2026-04-21)

모든 `.md` 문서는 GitHub.com 또는 VSCode **GitHub Markdown Preview** 확장(`bierner.markdown-preview-github-styles`)에서 렌더링된 결과를 기준으로 작성한다.

**Why:** 사용자가 VSCode에 GitHub Markdown Preview 확장을 설치해 GitHub 렌더링 기준으로 문서를 읽음. 일관된 시각적 품질을 위해 GitHub이 네이티브 지원하는 GFM 확장 문법(Alert blocks, Mermaid 등)을 적극 활용한다.

**How to apply:**

- **다이어그램**: ASCII art 금지. ` ```mermaid ` 코드 블록 사용
  - 브랜치 흐름 → `gitGraph`
  - 절차·의사결정 → `flowchart LR` 또는 `flowchart TD`
  - 시스템 상호작용 → `sequenceDiagram`
  - 상태 전환 → `stateDiagram-v2`
  - 일정 → `gantt`
- **강조/경고**: 일반 인용(`>`) 대신 GitHub Alert 구문 사용
  - `> [!NOTE]` 참고 정보
  - `> [!TIP]` 권장 방법
  - `> [!IMPORTANT]` 핵심 사항
  - `> [!WARNING]` 주의 사항
  - `> [!CAUTION]` 치명적 경고(보안·데이터 손실 등)
- **코드 블록**: 언어 항상 명시 (` ```bash `, ` ```powershell `, ` ```c `, ` ```json `, ` ```mermaid ` 등)
- **표**: 구조화된 정보는 표로. 정렬이 필요하면 `:---`, `:---:`, `---:` 사용
- **링크**: 파일 간 링크는 상대경로. 공백은 `%20` 인코딩
- **체크리스트**: 할 일·절차 목록은 `- [ ]` / `- [x]` 사용
