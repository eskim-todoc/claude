# 이력 및 결과 — 커스텀 알림 팝업

**TL;DR**: Slack 앱 기본 토스트는 색 커스텀이 불가해, 작업 완료 시 PC 우하단에 **웜 페이퍼(크림 베이지+테라코타) 커스텀 팝업**을 별도로 띄운다. Slack DM은 유지. 디자인은 시안 변형 **B(글로우 아이콘)**, 표시 6초. WPF/PowerShell로 구현해 `slack-notify.ps1`에 백그라운드 연동. 본 문서는 8단계 진행 로그.

## 완료 요약

**결과**: 작업 완료 시 화면 우하단에 웜 페이퍼(크림 베이지+테라코타) WPF 팝업(변형 B·6초)이 Slack DM과 병행 표시된다.

**산출물**
- `tools/toast-notify.ps1` (신규) — WPF 우하단 토스트. `tdc_Show-CompletionToast`·`tdc_Build-SparkGeometry`(sunburst 벡터).
- `tools/slack-notify.ps1` (수정) — Slack POST 앞에 팝업 detached 기동 5줄(Slack 성공/실패와 독립).
- `지침/설정/완료 알림 팝업.md` (신규) + 인덱스 2곳(`지침/README.md`·`설정/README.md`) + `Slack 알림.md` 크로스링크.
- 8단계 산출물 8종 + 시안/렌더 증거 HTML(작업 폴더 보관).

**검증**: 구문 OK(BOM), 렌더샷으로 테마 정상, slack→팝업 연동 손자 프로세스 실측(§구현-검증.md).

**주요 이슈·해결**
- PS 5.1 BOM 없는 UTF-8 한글 오독 → BOM 저장으로 해결(지침 트러블슈팅 문서화).
- "테마 미적용" = 투명창 캡처 누락 + 동시 뜬 카카오톡 알림 착시 → 렌더샷 실측으로 규명(팝업은 정상).
- 대화형 stdin hang / Stop-Process self-kill → 자식 프로세스 실행·`$PID` 제외로 해결.

**Git**: `claude_feature_toast-notify` → `claude_develop` `--no-ff` 병합 → `origin` push (본 작업 종료 시점).
