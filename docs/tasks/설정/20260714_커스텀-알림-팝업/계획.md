# 계획 — 커스텀 알림 팝업

**TL;DR**: 신규 `tools/toast-notify.ps1`(WPF 팝업)을 만들고, `tools/slack-notify.ps1`에 팝업을 detached로 띄우는 3줄을 추가한다. `지침/설정/Slack 알림.md`에 연동을 문서화하고 시안을 작업 폴더에 보관. 구현→수동 트리거 검수→연동 검수→문서화 순. 롤백은 신규 파일 삭제 + 3줄 revert로 간단.

## 1. 산출물

| # | 파일 | 유형 | 내용 |
|---|---|---|---|
| 산출_1 | `tools/toast-notify.ps1` | 신규 | WPF 우하단 팝업(변형 B, 6초). `param($Summary,$Title,$Seconds)` |
| 산출_2 | `tools/slack-notify.ps1` | 수정 | Slack POST 뒤 팝업 detached 기동(≈5줄 추가) |
| 산출_3 | `지침/설정/Slack 알림.md` | 수정 | 팝업 연동·트러블슈팅 추가(또는 `지침/설정/완료 알림 팝업.md` 신설 — 구현 시 판단) |
| 산출_4 | `docs/tasks/.../알림-팝업-시안.html` | 신규(보관) | 확정 시안(변형 B 포함) 작업 폴더 사본 |

## 2. `toast-notify.ps1` 구조

```
param([string]$Summary = '작업이 완료되었습니다', [string]$Title = '작업 완료', [int]$Seconds = 6)
[Console] UTF8 인코딩
try { Add-Type -AssemblyName PresentationFramework, PresentationCore, WindowsBase } catch { exit 0 }

function tdc_Show-CompletionToast {
  # 1) XAML 정의 (여기 문서 문자열)
  #    Window(AllowsTransparency, WindowStyle=None, Topmost, ShowInTaskbar=false,
  #           Background=Transparent, ShowActivated=false)
  #     └ Border  card: bg #FBF7EE, CornerRadius 14, BorderBrush #E2D5BC, DropShadow
  #        └ Grid (아이콘 | 콘텐츠), 하단 progress
  #           - 아이콘: Ellipse 44 (RadialGradient #D9764F→#C15F3C→#A94E2E) + sunburst Path(크림)
  #           - row1: "Claude Code"(테라코타 11px) · 시각(muted, 우측)
  #           - Title 13.5/700 잉크, Summary 12.5 secondary (2줄 트림)
  #           - progress: 높이 3, 테라코타
  # 2) 위치: SystemParameters.WorkArea 우하단, 여백 16
  # 3) sunburst: 12개 스파이크 — PowerShell 루프로 좌표 계산해 StreamGeometry 생성
  # 4) 애니메이션: 슬라이드-인 0.4s(ease-out) → $Seconds 유지(DispatcherTimer) → 페이드아웃 0.5s → Close
  # 5) 클릭/× → 즉시 닫힘
  # 6) 하드 안전 타임아웃(예: $Seconds+3초) 후 강제 Close (위험_5)
}

try { tdc_Show-CompletionToast } catch { exit 0 }
```

- 색: `#FBF7EE`(카드)·`#E2D5BC`(테두리)·`#C15F3C`/`#A94E2E`/`#D9764F`(테라코타 3톤)·`#F5DECB`(progress 트랙)·`#33291C`/`#6B5C46`/`#6E5F48`(텍스트) — 테마 SSOT.
- 폰트: `Segoe UI`(Windows 기본, system-ui 계열) — Pretendard 미설치 대비.

## 3. `slack-notify.ps1` 수정 (산출_2)

`$message` 확정 이후, Slack POST 블록 근처에 추가:

```powershell
# 완료 팝업 (detached, 훅 즉시 반환 — 실패 무시)
try {
    $toast = Join-Path $PSScriptRoot 'toast-notify.ps1'
    if (Test-Path $toast) {
        Start-Process -FilePath 'powershell.exe' -WindowStyle Hidden `
          -ArgumentList '-NoProfile','-Sta','-ExecutionPolicy','Bypass','-File',$toast,$message | Out-Null
    }
} catch {}
```

- Slack POST 성공/실패와 **독립** — 팝업은 항상 시도, 실패는 삼킴(제약_2).
- `-Sta`로 WPF STA 확보, `-WindowStyle Hidden`으로 콘솔 숨김.

## 4. 구현 순서

1. `toast-notify.ps1` 작성.
2. **수동 트리거 검수**: `powershell -Sta -NoProfile -File tools/toast-notify.ps1 "테스트 요약 — 우하단 6초"` → 위치·색·글로우 아이콘·sunburst·슬라이드/페이드·6초 육안 확인.
3. 미세 조정(위치 여백·아이콘·타이포·시간).
4. `slack-notify.ps1` 연동 수정.
5. **연동 검수**: `slack-notify.ps1`에 인자로 요약 전달 실행 → Slack DM + 팝업 동시 확인.
6. `지침/설정/` 문서화(산출_3) + 시안 보관(산출_4).
7. ⑧ 구현-검증.md 작성.
