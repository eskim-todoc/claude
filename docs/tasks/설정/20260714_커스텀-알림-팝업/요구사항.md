# 요구사항 — 커스텀 알림 팝업

**TL;DR**: 작업 완료 시 Windows 우하단에 웜 페이퍼(크림 베이지+테라코타) 커스텀 팝업을 띄운다. 디자인은 시안 변형 B(글로우 아이콘), 6초 후 자동 사라짐. 기존 Slack DM 알림은 그대로 유지하고, 커스텀 팝업만 추가한다. Slack 앱 기본 토스트 자체는 변경 대상이 아니다(색 커스텀 불가).

## 1. 배경·문제

- 현재 `tools/slack-notify.ps1`은 Stop 훅에서 Slack Webhook으로 `✅ {요약}`만 POST한다.
- 은수님이 Windows 11에서 보는 알림창은 **Slack 데스크톱 앱이 렌더하는 OS 토스트** — 배경색·모양을 우리 코드로 바꿀 수 없다.
- 은수님 요구: "Claude 느낌(크림 베이지+살짝 주황) 알림창".

|---|---|---|

| 요구사항_2 위치·동작 | 화면 **우하단**에서 슬라이드-인 | 인터뷰 ① |
| 요구사항_3 디자인 | 시안 **변형 B(글로우 아이콘)** | 인터뷰 ② |

## 3. 범위 밖 (비목표)

- 비목표_1: Slack 앱 OS 토스트 자체의 색·모양 변경 (기술적으로 불가)
- 비목표_2: 다크 모드 (웜 페이퍼는 라이트 전용 — 테마 정책 §6)
- 비목표_3: 동시 다중 팝업 스택/큐 관리 (초기 버전 제외 — 겹침 허용 또는 최신 우선, 분석에서 결정)
- 비목표_4: macOS/Linux 지원 (Windows 11 전용)

## 4. 제약

- 제약_1: Windows 11 + PowerShell 환경. Stop 훅은 `async: true`로 호출됨.
- 제약_2: 기존 silent-failure 원칙 유지 — 팝업 실패가 Slack 알림·세션을 막으면 안 됨.
- 제약_3: 훅 프로세스는 즉시 반환되어야 함 — 6초 팝업이 훅을 붙잡으면 안 됨(백그라운드 분리 필요).
- 제약_4: 외부 모듈 의존 최소화(BurntToast 등 미설치 환경 고려) — 순수 .NET/WPF 우선.
- 제약_5: rules repo `tools/` 자산 + `.claude/settings.json` 훅 배선(Project scope, git 추적).
