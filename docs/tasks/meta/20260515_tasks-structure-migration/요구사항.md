# 요구사항: tasks 구조 마이그레이션 (Task β)

**TL;DR**: Task α (`docs-structure-redesign`)에서 결정한 4가지 정책 중 A·B·C를 5 repo의 기존 25 작업에 일괄 적용. `_archive/<모듈>/<작업>/` → `tasks/<모듈>/<작업>/` 복귀, `진행상황.md` → `이력 및 결과.md` 시계열 로그로 흡수, `작업 목록.md` 활성/완료 분리 → 단일 표 + `상태` 컬럼, `_archive/모듈 현황.md` → `tasks/모듈 현황.md` 위치 이전. Task α 자신도 변환 대상. Task γ(영속 콘텐츠 Wiki 통합)와 병렬 가능 (영역 독립).

## 1. 사용자 지시 원문

> "두 작업을 병렬로 가능하면 병렬로 진행해."
>
> 직전 합의: Task α(정책) 완료 → Task β(구조 마이그레이션)·γ(Wiki 통합) 후속, 두 후속 작업 병렬 진행.

## 2. 요구사항

### 요구사항_1 — Archive 폐지 적용 (A)

| 항목 | 정책 |
|---|---|
| 대상 | 5 repo `docs/tasks/_archive/<모듈>/<작업>/` 폴더 전부 |
| 동작 | `git mv _archive/<모듈>/<작업>/ <모듈>/<작업>/` — 작업 폴더를 활성 위치로 복귀 |
| `_archive/` 폴더 자체 | 폐지 (`.gitkeep` 도 안 둠) |
| 작업 수 | 루트 9 + Sound1 20 + auto-rtt-viewer 2 + ez8300-study 1 + sound1-fw-extractor 1 = **33 작업** (Task α 종료 후 기준) |

### 요구사항_2 — 진행상황·이력 통합 (B)

| 항목 | 정책 |
|---|---|
| 대상 | 모든 작업의 `진행상황.md` |
| 동작 | 각 작업의 `이력 및 결과.md`에 `## 시계열 로그` 섹션 추가 후 `진행상황.md` 내용을 그 안에 흡수. 그 후 `git rm 진행상황.md` |
| 형식 | 새 `이력 및 결과.md` 구조 (frontmatter + TL;DR + 단계 진척 + 시계열 로그 + 완료 요약) — [`작업 진행 규칙.md §3.3`](../../../지침/일반/작업%20진행%20규칙.md) |
| 정보 보존 | 진행상황의 결정·이슈·다음 동작 시계열 모두 보존. 이력의 완료 요약과 함께 한 파일에 |

### 요구사항_3 — 작업 목록.md 단일표 (C)

| 항목 | 정책 |
|---|---|
| 대상 | 5 repo `docs/tasks/작업 목록.md` |
| 동작 | `## 활성`·`## 완료` 분리 표 폐지 → `## 작업 목록` 단일 표 (status 컬럼 통합) |
| 컬럼 | `작업명 \| 모듈 \| 태그 \| 상태 \| 시작·완료 \| 폴더 \| 연계 \| 요약` |
| 폴더 링크 | `_archive/<모듈>/<작업>/` → `<모듈>/<작업>/` (archive 폐지 반영) |
| 갱신 이력 | `## 갱신 이력` 섹션 그대로 유지 |

### 요구사항_4 — 모듈 현황.md 위치 이전 + 작업 단위 2층 확장

| 항목 | 정책 |
|---|---|
| 대상 | 5 repo `docs/tasks/_archive/모듈 현황.md` |
| 동작 | `git mv _archive/모듈 현황.md 모듈 현황.md` (위치 이전) |
| 내용 | 기존 모듈 인덱스 유지 + 작업 단위 2층 표 추가 (직전 합의 옵션 A — 모듈 요약 표 + 모듈별 작업 표) |
| 작업 단위 표 | `작업 \| 완료일 \| 폴더` — 모듈 헤더 아래 |

### 요구사항_5 — Task α 자신도 변환 대상

본 Task β는 Task α 자신을 포함 — 직전 archive된 `docs-structure-redesign` 작업이 본 Task β에서 활성 위치로 복귀되고, 그 진행상황·이력이 통합됨. *자기 적용 면제* 받았던 Task α가 본 task에서 *후속 위임* 완료.

### 요구사항_6 — 외부 링크 일제 갱신

Task α는 archive 위치 변경만 정책으로 정의하고 외부 링크(다른 산출물에서 archive 경로 인용)는 그대로 둠. Task β에서 일제 갱신:

| 위치 | 갱신 |
|---|---|
| 각 작업 산출물 안 archive 인용 | `_archive/<...>/` → `<...>/` |
| 회고에서 작업 인용 | 위와 동일 |
| CLAUDE.md·지침 등에서 archive 인용 (있다면) | 위와 동일 |
