# 요구사항: sound1 지침 2종 루트 이전·범용화

**TL;DR**: sound1-fw-e8300 `docs/지침/`의 2종을 루트 지침으로 승격한다. ① **레지스터 변경 검증 체크리스트** — 5게이트 골격은 유지하되 I2C·IQS323 어휘를 제거하고 외부 IC·MCU peripheral 레지스터 + 클럭·GPIO·전원 등 시스템 설정 전반으로 범용화. ② **SW 밸리데이션 계층화 방법론** — 유닛/모듈/시스템 계층 모델을 루트 SSOT로 두고 코딩·리팩터링·문서 작성·계획 단계에 적용 훅을 건다. 원본은 삭제(루트 단일 출처).

## 1. 사용자 요청

> "`../projects/sound1-fw-e8300/docs/지침`에 있는 2가지 파일(레지스터 변경 검증 체크리스트, SW 밸리데이션 계층화 방법론)을 루트의 지침에 반영하고 싶어. 단, 레지스터 변경 검증 체크리스트에 대해서는 I2C와 IQS323에 대한 내용으로 국한되지 않고 범용적으로 모든 레지스터 및 하드웨어 설정에 관여될 때 체크해야할 항목이나 주의 사항등으로 만들어 주고 싶어. 그리고 SW 밸리데이션 계층화 방법론은 코딩 방법, 코드 리팩터링 방법, 문서 작성 방법, 프로그래밍 계획 단계에서 이 계층화를 염두에 두고 계획할 수 있는 방향으로 업데이트 하고 싶어. 어떻게 하면 좋겠어?"

### 모호 포인트 해소 (사용자 확정)

| 질문 | 확정 답 |
|---|---|
| 원본 sound1 2파일 처리 | **삭제** — 루트가 SSOT (중복 drift 방지) |
| 밸리데이션 계층화 확산 형태 | **신규 지침 1개(SSOT) + 기존 지침에 적용 시점·링크 훅** (내용 분산 삽입 아님) |
| 레지스터 체크리스트 "하드웨어 설정" 범위 | **레지스터 + 시스템 설정 전반** — 외부 IC(I2C/SPI)·MCU peripheral(MMIO) + 클럭 트리·GPIO·전원·인터럽트 우선순위 |
| sound1 원본 삭제 커밋 방식 | **"지침 폴더 제거" 단일 커밋** — 2파일 + 기삭제된 README. 은수님 미커밋 작업(`main.c` 99줄)은 **미접촉** |
| sound1 CLAUDE.md (편집 중간 상태) | **잘린 문장·지침 폴더 잔존 참조만 정합화** — 은수님이 삭제한 메타·기여흐름 섹션은 그대로 존중 |

## 2. 목표

- 목표_1 (레지스터 지침 범용화): 5게이트(비트 식별·데이터시트 근거·전후 시뮬레이션·부작용·불확실성)를 보존하되 벤더/버스 중립 어휘로 재작성. IQS323 고유어(Auto Re-ATI·Reseed·LTA·Power Mode)를 일반 개념(자동 보정·재시작, 저전력 모드 전환 시 설정 유지)으로 승격. 적용 대상을 레지스터 + 시스템 설정 전반으로 확장.
- 목표_2 (밸리데이션 계층화 승격): 유닛→모듈→시스템 계층·의존성 테스트 순서("A는 B 통과 전제")를 루트 지침 SSOT로 신설. 프로젝트 특화(오디오 예시·CFX 온타깃 모델)는 일반화하거나 배제.
- 목표_3 (4방향 훅): 계층화를 **코딩 방법**(유닛 경계 의식 설계·HW 의존 격리) / **리팩터링 방법**(동작 보존 + 계층 재분해) / **문서 작성**(계층 그래프·검증 라벨) / **계획 단계**(8단계 ⑤계획에서 유닛·모듈 분해와 테스트 순서 명시, ⑧구현 검증과 연결)에 링크 훅으로 연결.
- 목표_4 (원본 정리): sound1 `docs/지침/` 폴더 제거 + CLAUDE.md 잔존 참조 정합화. 루트 단일 출처 확립.
