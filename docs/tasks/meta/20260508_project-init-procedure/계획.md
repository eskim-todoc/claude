# 프로젝트 초기 세팅

**TL;DR**: 사용자가 projects/<이름>/을 git clone한 뒤 자유 표현 트리거를 쓰면 ① 진단 → ② CLAUDE.md → ③ 표준 폴더 풀 세트 → ④ 루트 CLAUDE.md Projects 표 갱신 → ⑤ Git 처리(자동 push)의 5단계로 처리한다. 본 절차는 4단계 작업 진행 면제 (정형 반복).

## 1. 트리거 (자유 표현)

다음 키워드가 사용자 메시지에 포함되면 본 절차 적용:

| 키워드 패턴 | 예 |
|---|---|
| "새 프로젝트 생성" / "신규 프로젝트" | "프로젝트 폴더에 새 프로젝트 생성했어, 기본 세팅 해줘" |
| "초기 세팅" / "기본 세팅" / "초기화" | "projects/X 초기 세팅 부탁" |
| "표준 구조 적용" | "지금 클론한 프로젝트에 표준 구조 적용" |
| 명시 경로 | "projects/<이름> 세팅" |

## 2. 5단계 절차

(Mermaid flowchart로 표시)

### 2.1 단계 ① 진단

확인 항목:
- projects/<이름>/ 폴더 존재
- .git/ 존재 (git repo 여부)
- git remote -v로 origin URL 추출
- 기본 브랜치
- CLAUDE.md 존재 여부 — 있으면 사용자 확인
- src/·tests/·docs/ 존재 여부 — 보존

### 2.2 단계 ② CLAUDE.md 작성

§3 템플릿 그대로 적용. 자동 추출 가능 항목은 채우고, 나머지는 _(TBD)_ placeholder.

### 2.3 단계 ③ 표준 폴더 풀 세트

폴더 풀 세트 (이미 있으면 보존). 빈 폴더는 .gitkeep 추가.

### 2.4 단계 ④ 루트 CLAUDE.md Projects 표 갱신

§Projects 표에 한 줄 추가 (성격·비고는 placeholder).

### 2.5 단계 ⑤ Git 처리

프로젝트 repo·루트 repo 각각 feature → develop 머지 → push. default branch 보호 차단 시 옵션 제시.
