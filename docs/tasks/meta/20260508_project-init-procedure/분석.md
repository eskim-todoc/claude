## 3. 결정 사항

### 결정_1 — 템플릿은 본 지침에 인라인

| 옵션 | 평가 |
|---|---|
| A. 인라인 (지침 본문에 코드 블록) | ✅ 채택. lazy loading·템플릿 진화 추적 용이 |
| B. 별도 파일 (`templates/project-CLAUDE.md.template`) | ❌ 한 곳에 더 — 템플릿 폴더 신설 부담 |

### 결정_2 — 기존 CLAUDE.md·폴더 있을 때

| 시나리오 | 처리 |
|---|---|
| CLAUDE.md 없음·표준 폴더 없음 | 모두 신규 생성 (정상 케이스) |
| CLAUDE.md 있음 | 사용자에게 확인 — *덮어쓸까요? / 보존하고 일부만 추가할까요?* (이분 yes/no) |
| 표준 폴더 일부 있음 | 없는 폴더만 추가, 기존 비파괴 |
| `docs/tasks/작업 목록.md` 있음 | 보존, 헤더 정합성만 점검 |

> [!NOTE]
> 기존 CLAUDE.md가 있다는 건 이미 누군가 세팅한 프로젝트일 가능성. 보수적으로 접근.

### 결정_4 — Git 처리 분기

| 분기 | 동작 |
|---|---|
| 프로젝트 repo claude_develop 있음 | feature → claude_develop 머지 → push origin claude_develop |
| 프로젝트 repo claude_develop 없음 | claude_main 베이스로 claude_develop 신설 → feature 머지 → push -u origin claude_develop |
| default branch 보호 차단 | 사용자 옵션 제시 (PR 흐름·develop 신설·권한 추가) |
| 첫 commit 메시지 | `chore(init): <프로젝트명> 표준 세팅 (CLAUDE.md + 표준 폴더)` |
