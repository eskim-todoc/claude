# 요구사항: 새 프로젝트 초기 세팅 절차 신설

**TL;DR**: `projects/` 아래 git clone으로 새 프로젝트가 생긴 뒤 사용자가 자유 표현 트리거를 쓰면 Claude가 ① CLAUDE.md(슬림 패턴) ② 표준 폴더 풀 세트 ③ 루트 CLAUDE.md Projects 표 갱신을 정형 절차로 자동 수행한다. TL;DR·담당범위는 placeholder, push까지 자동, 4단계 면제.

## 1. 사용자 요청

사용자 지시 원문:

> "지금 작업한 것과 같이 프로젝트 별로 CLAUDE.md를 자동으로 설정되게 하고 싶거든? 내가 프로젝트 폴더에 깃에서 클론한 저장소가 폴더로 생성되면, 지금 Sound1이나 auto-rtt-viewer 처럼 말이야. ... '지금 프로젝트 폴더에 새 프로젝트 생성했어. 필요한 기본 세팅 해줘'와 같은 말을 하면 지금 했던 것과 같은 CLAUDE.md 세팅하고, 기본적으로 구성되어야할 세부 폴더들 딱 세팅하고. 그렇게 했으면 좋겠어. 그 다음 루트에서도 구성 중인 프로젝트 업데이트까지 하고."
>
> 합의 옵션 (Q1=A·Q2=B·Q3=A·Q4=A·Q5=A): 자유 트리거 / placeholder / 풀 세트 폴더 / push까지 자동 / 4단계 면제.

## 2. 목표

### 요구사항_1 — 트리거 인식 (자유 표현)

| 항목 | 내용 |
|---|---|
| 트리거 형태 | 자유 표현 키워드 매칭 (슬래시 명령 아님) |
| 키워드 예 | "새 프로젝트 생성", "기본 세팅", "프로젝트 초기화", "초기 세팅 해줘", "projects/X 세팅" |
| 적용 조건 | 사용자가 `projects/<이름>/`을 막 git clone한 시점 (또는 그에 준하는 신규 폴더 생성) |
| 모호 시 | [`명령 해석 규칙.md`](../../../지침/일반/명령%20해석%20규칙.md)에 따라 어느 프로젝트인지·표준 적용 여부 질문 |

### 요구사항_2 — 정형 절차 5단계 (4단계 면제)

| 단계 | 동작 |
|---|---|
| ① 진단 | 대상 폴더 존재·git repo 여부·기존 CLAUDE.md·기존 파일 점검 |
| ② CLAUDE.md 작성 | Sound1·auto-rtt-viewer 슬림 패턴 (frontmatter+TL;DR + Alert + 충돌 정책 + §메타·§Layout·§작업 라우팅) |
| ③ 표준 폴더 풀 세트 | `src/`·`tests/`·`docs/{지침,사용방법,참고}/`·`docs/tasks/작업 목록.md` |
| ④ 루트 CLAUDE.md 갱신 | Projects 표에 한 줄 추가 (이름·성격·비고) |
| ⑤ Git 처리 | 프로젝트 repo·루트 repo 각각 feature 브랜치 → 커밋 → develop 머지(--no-ff) → push (default branch 보호 시 develop 신설 후 push) |

### 요구사항_3 — placeholder 정책 (Q2=B)

| 항목 | 처리 |
|---|---|
| Repository (`origin` URL·main branch) | git remote -v로 자동 추출, fail 시 `_(TBD)_` |
| TL;DR 한 줄 | `_(TBD: 프로젝트 1줄 설명)_` placeholder |
| 담당 범위 | `_(TBD)_` placeholder |
| Layout 세부 (언어·프레임워크) | 기본 풀 세트로 채우고 사용자가 나중에 수정 |

### 요구사항_4 — 자동화 한계 명시

다음은 사용자가 나중에 채우는 것을 안내(commit 메시지·이력에 placeholder 위치 표기):

- TL;DR 본문
- 담당 범위
- 활용처(다른 프로젝트 연계 시)
- 메타의 비고

### 요구사항_5 — Git 처리 (Q4=A 자동 push)

| 항목 | 동작 |
|---|---|
| 프로젝트 repo | feature → develop 머지 → `push origin claude_develop`. develop 미신설 시 신설(claude_main 베이스) |
| 루트 repo | feature → develop 머지 → `push origin claude_develop`. CLAUDE.md Projects 표 갱신만 |
| default branch 보호 차단 | sullivan 사례처럼 옵션 제시 (PR 흐름·develop 신설·권한 추가) |
