## 1. 실행 단계 (오케스트레이터 직접)

### Step 1: 서브에이전트 활용.md
- TL;DR: 전면 위임 → 트리거 기반 + effort 미지정(Sonnet adaptive)
- §1 표: 활용 강도 "전면 위임"→"트리거 기반", 우선 고려 문구
- §1 IMPORTANT: 전면 위임 정책 → 트리거 기반 오케스트레이션 정책(트리거어 목록·판단 기준)
- §1.1: 제목 "유일한 예외"→"오케스트레이터가 직접 하는 일", 항목 5(트리거 없는 간단 작업 직접) 추가, CAUTION은 "트리거/실익 시 미루지 말고 위임"으로 반전
- §2.1 표: "사용자 답변 위한 조회→위임(effort max)" 행을 "트리거 없는 간단→직접 / 트리거·다중페르소나·병렬→dynamic workflow"로
- §3.1: 문단·표·IMPORTANT를 effort 미지정(세션 상속)·Sonnet adaptive로. CAUTION(결정론적 저술)은 "직접" 유지·max 문구 정리
- §5 안티패턴: "직접 처리=안티패턴" 행 → 과소 위임/과잉 위임 2행으로
- §6 표: ②④ 문구 트리거·effort 정합

### Step 2: 워크플로우 오케스트레이션.md

### Step 3: CLAUDE.md §5
