# 요구사항 — 워크플로우 오케스트레이션 이식

**TL;DR**: `ai/rules/`(별도 헌법 체계)의 **서브에이전트·워크플로우 관련 지침만** 골라 루트(`E:\Claude`) `docs/지침/`에 반영한다. 핵심은 루트에 통째로 빠진 **워크플로우 오케스트레이션**(4대 패턴·검증 루프·fan-in 예산·fan-out 경계)을 신규 지침으로 신설하고, 기존 `서브에이전트 활용.md`에 누락된 **fan-in 컨텍스트 예산·adversarial-verify 예외**를 보강하는 것.

## 1. 배경

- 은수님 지시: "루트 헌법/지침 읽고 그대로 업데이트 해. 그리고 `/mnt/c/Users/KES0481/ai/rules/` 헌법/지침에서는 서브에이전트/워크플로우 관련 사항만 이용하도록 해."
- 루트(`E:\Claude`)와 `ai/rules/`는 **별개 헌법 체계**다. 본 작업은 루트를 정본으로 두고, `ai/rules/`에서는 **서브에이전트/워크플로우 관련 사항만** 추출해 루트에 흡수한다.

## 2. 요구사항 항목

- 요구사항_1: `ai/rules/`에서 **서브에이전트·워크플로우 관련 내용만** 추출 대상으로 한정한다. (자기-신고·온디맨드·Memory·하네스 충돌 등 rules 고유 메타는 제외)
- 요구사항_2: 루트에 **통째로 누락된** 워크플로우 오케스트레이션(4대 패턴·검증 루프·fan-in 예산·fan-out 경계·동시성)을 루트 `docs/지침/일반/`에 **신규 파일로 분리**해 신설한다.
- 요구사항_3: 기존 루트 `서브에이전트 활용.md`에 누락된 **fan-in 컨텍스트 예산**과 **adversarial-verify 예외**를 보강한다.
- 요구사항_4: `ai/rules/` 고유 하네스 용어(`H-2.5`·`단계_4`·`표준-프로세스`)는 **루트 4단계(①②③④) 체계로 번역**해 루트 내부에서 broken reference가 생기지 않게 한다.
- 요구사항_5: 신규/수정 문서는 루트 문서 메타 규칙(frontmatter·TL;DR·maturity·GFM·Mermaid)을 준수한다.
- 요구사항_6: 인덱스 정합 — `CLAUDE.md` 지침 표·`작업 규칙.md`·관련 지침 cross-link를 신규 지침에 맞춰 갱신한다.

## 3. 사용자 확정 결정 (인터뷰)

- 반영 구조: **신규 파일 분리** (`docs/지침/일반/워크플로우 오케스트레이션.md` 신설 + `서브에이전트 활용.md`에 fan-in 보강) — `ai/rules/`의 2파일 구조 미러링.
- 용어 정합: **루트 4단계로 번역** (`단계_4`→`단계 ④`, `H-2.5 승인 게이트`→루트 단계 ③ 계획 승인 게이트).

## 4. 범위 밖 (Out of Scope)

- `ai/rules/`의 자기-신고·온디맨드 트리거·Memory 정책·하네스 충돌표 등 비-서브에이전트/워크플로우 항목.
- `ai/rules/` 자체의 수정 (단방향 추출만, 원본 불변).
- Sound1 등 프로젝트 repo 지침 (루트 한정).

## 5. 자체 검토

- 지침 준수: 모호성(반영 구조·용어 정합) 2건 인터뷰로 해소 후 착수 — 명령 해석 규칙 부합.
- 논리 정합: 추출 대상을 "서브에이전트/워크플로우"로 한정해 은수님 지시 문구와 1:1 대응.
