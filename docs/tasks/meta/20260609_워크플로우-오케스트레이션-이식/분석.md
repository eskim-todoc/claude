# 분석 — 워크플로우 오케스트레이션 이식

**TL;DR**: `ai/rules/`의 서브에이전트·워크플로우 2파일과 루트 `서브에이전트 활용.md`를 대조. 루트는 단발 위임·병렬까지만 커버하고 **오케스트레이션 4패턴·검증 루프·fan-in 예산·fan-out 경계·동시성**이 통째로 누락. 추가로 fan-in 예산·adversarial-verify 예외도 미보유. 용어는 rules 하네스 ID(`H-2.5`·`단계_4`)를 루트 4단계로 번역해야 정합.
