**TL;DR**: 5개 파일 변경. ① 워크플로우 오케스트레이션 지침 신설 → ② 서브에이전트 활용.md 보강(fan-in 예산·adversarial 예외·링크) → ③ CLAUDE.md 인덱스 정합 → ④ 작업 규칙.md 최소 링크 → ⑤ tasks 등재. 모든 rules 하네스 용어는 루트 4단계로 번역.

## 변경 단계

### 단계_1 — 신규 `docs/지침/일반/워크플로우 오케스트레이션.md`

`ai/rules/AI운영/워크플로우-오케스트레이션.md`를 루트 4단계 체계로 번역해 신설. 구성:

- frontmatter(name/purpose/type/maturity:experimental/tags) + TL;DR
- §1 개념 — "도구가 아니라 패턴" (Workflow 도구 부재 시 Agent 다중 호출로 재현)
- §2 4대 오케스트레이션 패턴 — parallel·pipeline·loop-until-dry·adversarial-verify (표 + 트리거·매핑·실패 처리)
- §3 검증 루프 (단계 ④ 연동) — 검증 fan-out → fan-in → 루프백(단계 ③ 재승인 조건)·상한 3회
- §4 fan-in 컨텍스트 예산 — 노드 3줄 반환·reducer 1단·loop 상태 예외 (서브에이전트 활용과 cross-ref)
- §5 read-only/쓰기 fan-out 경계 — read-only는 단계 ③ 승인 전 상시, 쓰기는 승인 후
- §6 동시성 주의 — 병렬 쓰기 시 노드별 파일·디렉토리 분리
- §7 관련 지침 — 서브에이전트 활용·작업 진행 규칙·컨텍스트 절약 규칙

> 용어 번역은 분석.md §3 매핑표 적용. `agent_lock.py` 등 rules 전용 도구 경로는 루트에 없으므로 "수동 분리 회피" 원칙만 남기고 경로 인용 제거.
