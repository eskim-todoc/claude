```yaml
source_path: <원본 경로 — docs/사용방법/<파일>.md>
migrated_at: 2026-05-15
migrated_from_commit: <원본 repo의 본 변환 직전 commit SHA>
tags: [<기존>]
---
```

원본 본문 그대로 유지. frontmatter만 확장.
