# 계획 — 워크스페이스 아키텍처 개편 지침 반영

**TL;DR**: 활성 파일 15+종을 파일군별로 나눠 atomic commit 6개(Step 1~6)로 반영한다. Step 1 헌법 개편에 4단계 산출물을 동봉하고, Step 6에서 검증 grep·인덱스 등재·완료 요약·`claude_develop` 병합까지 마친다.

## Step 1 — CLAUDE.md 헌법 개편 (+ 4단계 산출물 동봉)

- `Root: E:\Claude` 서술 → workspace 형제 구조로: rules=헌법 저장소, projects=형제 독립 repo.
- Layout 다이어그램 재작성: `E:\workspace\` 엄브렐러 아래 `rules\`(CLAUDE.md·지침·docs·tools·credentials·.claude) + `projects\<name>\`(형제).
- gitignore 설명에서 `projects/` 제거.
- **Projects 표 전체 삭제** → "프로젝트는 `<workspace>/projects/`의 독립 형제 repo, 각자 CLAUDE.md로 self-describing, rules 미추적" 노트로 대체. "프로젝트 내부 표준 구조" 소절 유지.
- Credentials·Tools의 wiki 링크 절대경로화.
- 동봉: 요구사항.md·분석.md·계획.md·이력 및 결과.md.

## Step 2 — 지침/일반/프로젝트 초기 세팅.md 재작성 (최대 개정)

- 트리거를 "rules에서 projects/ 하위 스캐폴딩" → **"사용자가 clone한 프로젝트 폴더에서 세션 열고 세팅 명령"**으로.
- 절차 재설계: ①진단 ②CLAUDE.md(루트 헌법을 **절대경로**로 참조) ③표준 폴더 ④Git(그 프로젝트 repo만). **옛 "루트 Projects 표 갱신"·"루트 repo push" 단계 제거**(결정 1).
- CLAUDE.md 템플릿의 `../../CLAUDE.md` → `E:\workspace\rules\CLAUDE.md` 절대경로.
- 작업 디렉토리 예시 `E:\Claude` → 프로젝트 경로.
- §9 이식성 노트: "E:\Claude 폴더 복제" → "rules repo clone + 프로젝트별 개별 clone" 모델로.
- **추가**: 표준 폴더 세트에 `.claude/settings.json`(`{"worktree":{"bgIsolation":"none"}}`) 포함.

## Step 3 — Git 규칙 2파일

- `브랜치, 병합 규칙.md` §작업 스코프: "변경 파일 경로 기준 repo 결정"(중첩 전제) → **"세션이 열린 저장소 = 작업 대상, 각 repo 독립, 한 세션 한 repo"**로 단순화. `E:\Claude`→`E:\workspace\rules`.
- `워크플로우.md` §0 스코프 플로우차트·L277 학습노트: 루트 repo 경로·중첩 전제 정리.

- `위키 반영 절차.md` + `위키 배경지식 조회.md`: `projects/wiki` 접근을 절대경로(`E:\workspace\projects\wiki`)로, wiki가 형제 repo임을 명시.
- `에이전트 로그 구조.md`, `계획 모드 자동 진입.md`(deprecated): 경로 언급 정리.
