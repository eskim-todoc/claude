# 요구사항 — 워크스페이스 아키텍처 개편 지침 반영

**TL;DR**: 저장소가 `E:\Claude` 단일 git(그 아래 `projects/` 중첩)에서 `E:\workspace\`(git 아닌 엄브렐러) 아래 `rules/`(헌법 저장소)와 `projects/<name>/`(형제 독립 repo)로 재편됐다. 이 물리 구조 변화를 헌법(`CLAUDE.md`)·지침·기능 파일(훅·스크립트) 전반에 일관되게 반영해, 옛 경로(`E:\Claude`) 잔존·중첩 repo 전제·중앙 Projects 레지스트리를 제거한다.

## 1. 배경 (왜)

- **옛 구조**: `E:\Claude\` = 단일 git repo. 그 안에 `projects/<name>/`가 중첩된 독립 repo(git-under-git), `.gitignore`로 차단.
- **새 구조**: `E:\workspace\` = git 아닌 로컬 엄브렐러 폴더. 그 아래 `rules/`(이 저장소 = 헌법·지침)와 `projects/<name>/`가 **형제 독립 repo**. 각자 자기 `.git`. git-under-git 소멸.
- **워크플로우 변경**: 이제 rules에서 `projects/` 하위를 세팅하지 않는다. 새 프로젝트는 사용자가 직접 `workspace/projects/<name>/`로 clone → **그 프로젝트 폴더에서 세션을 열고** → 루트 헌법을 절대경로로 참조해 in-place 세팅한다.

## 2. 목표

1. 헌법·활성 지침·기능 파일에서 옛 경로(`E:\Claude`/`E:/Claude`)와 중첩 repo 전제를 제거하고 새 구조로 서술한다.
2. 훅·스크립트의 무음 실패(옛 경로 참조)를 실경로로 고쳐 기능을 복구한다.
3. 프로젝트 초기 세팅 절차를 새 워크플로우(사용자 clone → 프로젝트 폴더에서 세션)에 맞게 재작성한다.

## 3. 확정 결정 (AskUserQuestion, 2026-07-13)

| # | 결정 | 근거 |
|---|---|---|
| 결정 1 | **중앙 Projects 레지스트리 완전 폐지.** rules는 프로젝트 목록을 추적하지 않고, 각 프로젝트는 자기 CLAUDE.md로 self-describing. | 현재 `workspace/projects/`에 옛 표에 없는 프로젝트 다수 — 이미 현실과 어긋남. |
| 결정 2 | **머신 경로 표기: 구조 중심 서술 + 예시.** "workspace 엄브렐러 아래 rules + projects 형제" 구조로 서술하고 구체 경로는 `E:\workspace` 예시로만. 기술적으로 절대경로가 필요한 훅/설정만 실경로. | 이식성과 명확성의 균형. |
| 결정 3 | **크로스 repo 참조: 절대경로 표준.** wiki 등 다른 저장소 참조는 `E:\workspace\...` 절대경로(또는 전역 CLAUDE.md 포인터). | 형제 repo는 더 이상 상대경로로 안정 참조 불가. |

## 4. 범위

### 대상 (활성)

- `CLAUDE.md`(헌법), 활성 지침(`지침/**`), 활성 tasks 인덱스(`docs/tasks/README.md`·`모듈 현황.md`), 기능 파일(`.claude/settings.json`·`tools/*`·`.gitignore`·`.claude/memory/*`).

### 범위 외

- 과거 `docs/tasks/**` 작업 기록의 `E:\Claude` 언급(불변 스냅샷).
- 전역 `~/.claude/CLAUDE.md`·`~/.claude/settings.json`(사용자 스코프 자기설정 가드). 전역 포인터는 이미 `E:\workspace\rules`로 갱신됨.
- `workspace/projects/rules-tasks`(빈 저장소) 정리 — 별건.
