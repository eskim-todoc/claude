## 사용자 후속 과제

1. **GitHub Wiki repo default branch 변경** (필요 시): GitHub UI → `eskim-todoc/wiki` → Settings → Branches → Default branch를 `claude_main`으로 설정. 첫 push 순서상 `claude_main`이 기본으로 잡혔을 가능성이 높으나, 확인 권장.
2. **옵시디언으로 Vault 열기**: Obsidian → *Open folder as vault* → `E:\Claude\projects\wiki\` 선택. `.obsidian/` 자동 생성됨. 코어 설정 화이트리스트 5개(`app.json`·`appearance.json`·`core-plugins.json`·`community-plugins.json`·`hotkeys.json`)는 첫 설정 마친 뒤 `git add` + 커밋해 다른 기기와 환경 공유 가능.
3. **추후 웹 공개** (선택, 별도 작업): Quartz 4 도입 시 한국어 폴더·파일명 OK, 헤딩 앵커는 영문/숫자 슬러그 권장(비ASCII 미지원, [Quartz issue #1155](https://github.com/jackyzha0/quartz/issues/1155)). GitHub Pages private은 GitHub Pro($4/월) 또는 Cloudflare Access 등 프록시 필요.
