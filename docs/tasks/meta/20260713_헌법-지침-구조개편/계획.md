# 계획 — 헌법·지침 구조 개편 최종 설계 (검증 반영 v2)

**TL;DR**: 6설계안·4심사 합성 후 **8렌즈 adversarial 검증**으로 실행 디테일 구멍(blocker 3·high 다수)을 보정한 최종안. **CLAUDE.md 슬림 라우터**(하네스 자동주입으로 안전, 단 되돌리기 어려운 사실은 리터럴 잔존), **README SSOT 인덱스**·**작업 규칙.md SSOT 체크리스트**, **서브에이전트/·문서/·설정/·공통/ 최상위 카테고리**, **검증 하네스**(3축·단계 게이트·dedup-check·deprecation 리플·**결정론적 링크체커**). 구현은 **각 이동마다 역참조+아웃바운드+지침밖 참조를 명시 목록으로** 갱신하고 그 자리에서 grep 재검증. 원본: [`첨부_설계_6안-4심사.json`](첨부_설계_6안-4심사.json)·[`첨부_검증_설계8렌즈.json`](첨부_검증_설계8렌즈.json).

## 3. 4단계 검증 하네스 (R3) 상세

`4단계-프로세스.md` 자체검토 **2축→3축**(+근거검증) + §신설 "할루시네이션 방지 검증 게이트":
- **①요구사항**: 지시 재진술(괴리=오해 신호)·모호점 표·인터뷰 질문 강제·"추정/아마도" 금지.
- **②분석**: 모든 사실 `파일:라인` 근거 의무·미확인 마커·작성후 재대조 패스.
- **③계획**: "왜 틀릴 수 있나" ≥1·경로변경은 영향참조 전수 Grep 첨부·**이동으로 상대깊이 바뀌면 이동전/후 hop 수 나란히 명시**.
- **④구현**: 이동 직후 (a)구경로 리터럴 Grep 0 **+ (b)결정론적 링크체커로 bare 상대링크까지 실존 검사**(grep 사각지대 보완)·대규모(정량)는 adversarial-verify.
- **재사용 자산**: `tools/check-links.ps1`(결정론) + `문서/작성-스타일.md` BFS 레시피(LLM은 2차) — R3·R9 공유.
- **deprecation 리플**(완료처리.md): 폐지 커밋은 역링크 동시 정리해야 완료.
- **dedup-check**(메타-frontmatter.md): 신규 .md 전 Grep으로 기존 SSOT 확인→링크만.
- **정량 adversarial 트리거**(오케스트레이션.md): 3파일↑ 이동/개명·credentials·CLAUDE.md 변경 → 독립 검증 노드 ≥1.

## 5. 구현 순서 (검증 반영 세분화)

원칙: 정책 선행→이동 후행, 각 이동마다 **(a)역참조 inbound + (b)형제 아웃바운드 + (c)지침/ 밖 참조**를 명시 목록으로 갱신·즉시 grep+링크체커 재검증. 각 단계 최소 1커밋.

**S0 자기적용 보강** _(완료)_: 요구사항·분석·계획에 자체검토 소급.
**S1 선정정**: README 인덱스 drift 3건(에이전트로그구조·커밋메시지·계획모드 maturity) + 컨텍스트 절약 §6 죽은 링크. *이동 전 유실 방지*.
**S2 링크체커 + tools/README**: `tools/check-links.ps1` 신설(모든 .md 상대링크 실존 검사) + `tools/README.md`. 이후 모든 이동 단계가 이 체커로 검증.
**S3 정책 신설(비이동 파일만)**: 4단계-프로세스 3축+게이트, 완료처리 deprecation 리플, 작업 진행 규칙 단순수정 면제 SSOT. *메타-frontmatter dedup-check는 이동 대상이라 S6로 연기*.
**S4 credentials → tools/credentials**: git mv + 코드 2곳(slack L4·rename L25) + 문서(CLAUDE·memory/github·프로젝트초기세팅 261·rename README 43-44) + credentials/README 전면 재작성 + tools/README 반영 + **slack 훅 수동 테스트**.
**S5 서브에이전트/ 신설·이동**: 3파일 git mv+개명 + README + 마스터표 카테고리 행. 역참조: CLAUDE·README·작업규칙·**컨텍스트 절약 규칙 106**·4단계-프로세스·양식/계획·오케스트레이션 상호. 삭제예정 계획모드 인용도 포함.
**S6 문서/ 최상위 승격**: 일반/문서/(3)+문서 테마 스타일→테마 토큰+테마/+작업/양식/ 이동·개명 + README(유일 인덱스)·작성 규칙 §2표 삭제 + 양식 검증게이트 + 폴더-구조 깊이정책·§1트리 + 작성-스타일 깨진경로3·레시피 + 메타-frontmatter dedup-check·진입점 예외. **역참조 명시**: CLAUDE·README·작업규칙·**Git/커밋 메시지 114·코딩/작업 규칙 66·완료처리 16·에이전트로그구조(이중이동)·4단계-프로세스 56-62·작업 진행 규칙·프로젝트 초기 세팅·docs/tasks/README 11·45**. **아웃바운드**: 이동 8파일 자기 링크 재계산(테마 토큰 255 등). 각 하위이동 후 링크체커.
**S7 설정/ 신설**: Slack 알림·Statusline·스피너 설정 작성 + README + **마스터표 행**. statusline은 사용자 홈 고정(예외 명시), tools/ 사본 여부는 문서에 사유 기록.
