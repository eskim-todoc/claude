# 계획 — 헌법·지침 구조 개편 최종 설계

**TL;DR**: 6설계안·4심사(온디맨드무결성·유지보수성·관심사분리·안전장치) 교차평가를 합성한 최종안. **CLAUDE.md를 슬림 라우터로 축소**(하네스가 전문을 자동 주입하므로 안전, 단 되돌리기 어려운 사실은 리터럴 잔존+SessionStart 훅 강화), **지침/README.md를 SSOT 인덱스**·**작업 규칙.md를 SSOT 체크리스트**로 단일화, **서브에이전트/·문서/·설정/·공통/를 Git·코딩과 동급 최상위 카테고리로** 재편, **4단계에 검증 하네스**(3축 자체검토·단계별 게이트·dedup-check·deprecation 리플·BFS 링크점검)를 심는다. credentials→tools/credentials. 정책 개정 선행 → 물리 이동 후행, R별 최소 커밋. 원본 심사는 [`첨부_설계_6안-4심사.json`](첨부_설계_6안-4심사.json).

## 3. 4단계 검증 하네스 (R3 — 할루시네이션 방지) 상세

`4단계-프로세스.md` 자체검토를 **2축→3축**(지침준수·논리정합성 + **근거검증**)으로 격상하고 §신설 "할루시네이션 방지 검증 게이트":

- **① 요구사항**: 사용자 지시를 Claude 언어로 재진술(괴리=오해 신호). 모호점 표+인터뷰 모드 질문 강제. "추정컨대/아마도" 미검증 서술 금지, 사실↔해석 분리.
- **② 분석**: 모든 사실은 `파일:라인` 근거 동반 의무(Read/Grep 확인 없이 인용 금지). 미확인은 `(미확인)` 마커. 작성 후 인용 재대조 패스 1회.
- **③ 계획**: "왜 틀릴 수 있는가" 실패 시나리오 ≥1. 경로·파일명 변경 계획은 영향 참조 전수 Grep 첨부.
- **④ 구현**: 이동·개명 직후 구 경로 리터럴 전역 Grep 0 확인(과거 tasks 제외). 변경 .md 링크 실존 확인. 대규모는 저술↔검증 노드 분리(adversarial-verify).
- **재사용 자산**: 온디맨드 링크 무결성 점검 절차(BFS 크롤+orphan/broken 판정)를 `문서/작성-스타일.md`에 1곳 기술 → R3·R9 공유 참조.
- **deprecation 리플**(완료처리.md): 파일 폐지 커밋은 역링크를 동시 정리해야 완료 인정.
- **dedup-check**(메타-frontmatter.md): 신규 .md 작성 전 Grep으로 기존 SSOT 확인 → 있으면 링크만.

## 5. 구현 순서 (atomic 커밋, 정책 선행 → 이동 후행)

각 단계 = 최소 1커밋(롤백 지점). 안6 순서 규율 채택.

1. **선정정**: README 인덱스 drift 3건(에이전트로그구조·커밋메시지·계획모드 maturity) + 죽은 링크(컨텍스트 절약 §6) — *이동 전 유실 방지*.
2. **검증 하네스·재발방지 정책 신설**: 4단계-프로세스 3축·게이트, 완료처리 deprecation 리플, 메타-frontmatter dedup-check + 진입점 frontmatter 예외.
3. **credentials → tools/credentials**: git mv + 참조 2곳 코드 + 문서(CLAUDE·memory·프로젝트초기세팅·rename README) + tools/README·credentials/README 신설 + slack 훅 수동 테스트.
4. **서브에이전트/ 신설·이동**: 3파일 git mv+개명 + README 신설 + 역참조 링크 갱신(~8파일).
5. **문서/ 최상위 승격**: 일반/문서/·문서 테마 스타일·테마/·작업/양식/ 이동 + 개명 + README 신설 + 양식에 검증 게이트 + 폴더-구조 깊이정책 + 작성-스타일 BFS레시피·깨진경로 + 역참조 갱신.
6. **설정/ 신설**: Slack 알림·Statusline·스피너 문서 작성 + README.
7. **공통/ 신설**: 경로·참조 표기 흡수 + README.
8. **SSOT 중복 축약**: §4 매핑대로 각 파일 1줄+링크화.
9. **Projects 잔재**: CLAUDE Layout Sound1 제거·표준구조 트리 삭제, Sound1 각주 일반화.
10. **CLAUDE.md 슬림화** + SessionStart 훅 강화 + README 링크.
11. **계획모드 삭제**: 인용 5곳 정리(deprecation 리플 적용) + git rm.
12. **온디맨드 검증 workflow**: BFS 링크 크롤 + 시나리오 테스트 + 구경로 Grep 0 (서브에이전트 대량, R10 30%).
13. **완료 처리**: 작업 목록·모듈 현황 등재, 이력 요약, claude_develop 병합.

## 6. 검증 계획 (R9·R10)

- **설계 검증**(구현 전): 본 계획을 adversarial 서브에이전트로 반박·리스크 재점검 → 보정.
- **구현 후 온디맨드 검증**(서브에이전트 대량, ≥30%): ① CLAUDE.md 기점 BFS 링크 크롤 — orphan/broken 0. ② 시나리오 질의 테스트(직접 수행) — "Git 정책?"·"서브에이전트 언제?"·"credential 위치?" 등 ≤2-hop 도달. ③ 구 경로 리터럴 전역 Grep 0(살아있는 문서). ④ frontmatter·TL;DR 준수 전수.

## 7. 범위 외

- 각 지침 **정책 내용 자체의 재작성**(구조·중복·링크·하네스만). 
- 과거 `docs/tasks/**` 스냅샷, 형제 wiki repo(후속).
- github/ssh-key 삭제(참조 0건 고아지만 이번엔 이동만 — 사용자 확인 사안).
