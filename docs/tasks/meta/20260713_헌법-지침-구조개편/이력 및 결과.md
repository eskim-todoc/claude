## 완료 요약

**서브에이전트 R10 배분:** 총 37노드 — 분석 9(24%) · **구조 설계+검증 18(49%)** · **구현 후 온디맨드 검증 10(27%)**. 은수님 지시(설계·검증 50%·구현검증 30%) 근접 충족.

### 무엇을 했는가
헌법·지침 구조를 온디맨드 진입 체계로 전면 개편. CLAUDE.md를 슬림 라우터(핵심지침 초압축 + `지침/README.md` SSOT 링크)로 축소해 진입점 3중복(CLAUDE·README·작업 규칙)의 이중 인덱스 drift를 해소. 서브에이전트·문서(테마·양식 흡수)·설정·공통을 Git·코딩과 동급 최상위 카테고리로 재편. credentials를 `tools/credentials/`로 이동. Projects 경로 잔재 제거, 계획 모드(deprecated) 삭제. 4단계 프로세스에 할루시네이션 방지 검증 하네스(3축 자체검토·§3.4 단계별 게이트·deprecation 리플·dedup-check·결정론적 링크체커)를 심었다. 서브에이전트 대량 오케스트레이션(37노드)으로 설계·검증했고, 승인 대기 없이 미리 커밋 후 구현까지 자율 진행(롤백 지점 촘촘히).

### 핵심 결정
- **CLAUDE.md 슬림화 안전성** — 하네스가 전문을 매 세션 자동 주입한다는 실증(이 세션 자체)에 근거. 단 되돌리기 어려운 규칙은 리터럴 잔존 + SessionStart 훅 강화(scope caveat 명시).
- **문서/ 최상위 승격** — 관심사 분리 심사 최고점. 4레벨 깊이는 문서/테마·문서/양식·일반/작업 한정 예외로.
- **공통/ 최소 스코프** — 무주공산(경로·참조 표기)만. 대부분 중복은 기존 SSOT 귀속(그랩백 방지).
- **결정론적 링크체커 도입** — LLM BFS보다 신뢰. 단 코드펜스 정규식 버그가 온디맨드 검증에서 드러나 근본 수정(교훈: 검증 도구 자체도 adversarial 검증 대상).

### 후속 영향
- 향후 신규 지침은 `지침/README.md` 표만 갱신(단일 인덱스). 폐지 시 deprecation 리플 규칙 적용.
- wiki repo·형제 프로젝트의 지침 참조는 각 repo가 루트 헌법을 절대경로로 참조(별건).
- 링크체커에 회귀 테스트 fixture 추가는 후속 개선 여지(검증 노드 권고).
