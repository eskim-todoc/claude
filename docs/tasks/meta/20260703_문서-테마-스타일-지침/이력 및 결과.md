### 무엇을 했는가
nofm HTML 뷰어의 웜 페이퍼 테마(크림 배경·다크 브라운·테라코타/틸 액센트, 라이트)를 도메인 무관 디자인 시스템으로 추출해 루트 전역 지침으로 신설. 인덱스 `문서 테마 스타일.md`(색 25종·타이포·컴포넌트 토큰 SSOT + GitHub 렌더 현실 + 유지보수) + `테마/{HTML-아티팩트, Mermaid, Obsidian}.md` 3트랙. 액센트는 역할 기반 재명명(`--accent-1/2`, 원본 cis/nofm 매핑 주석). 작성-스타일 §4.3.2 앵커·README·CLAUDE.md 등재.

### 핵심 결정
- 액센트 도메인 무관 재명명(accent-1/2), SSOT가 역할 1개 고정 → 3트랙 종속
- 토큰 자체완결(원본 링크는 각주 — gitignored repo라 취약)
- 라이트 전용(Mermaid 배경무관·Artifact 단일톤·Obsidian 라이트 전환)
- Mermaid stroke=잉크·액센트(옅은 구분선 토큰 stroke 시 대비 실패 발견)

- 기존 §4.3.2 Mermaid 팔레트 WCAG 미달(3/5) 별도 후속 교정 필요(기록만)
