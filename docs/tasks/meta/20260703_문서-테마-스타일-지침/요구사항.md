# 요구사항: 문서 테마 스타일 지침

**TL;DR**: 은수님이 선호하는 `nofm-output-pattern-viewer.html`의 웜 페이퍼 테마(크림 배경·다크 브라운 텍스트·테라코타+틸 액센트, 라이트)를 도메인 무관 디자인 시스템으로 추출해, 루트 전역 지침(`docs/지침/`)에 신설한다. 적용 대상 4종: (1) HTML 뷰어·아티팩트(CSS 변수 테마+스니펫), (2) Mermaid 다이어그램(팔레트 매핑), (3) Obsidian·wiki(CSS 스니펫), (4) 이 셋이 참조하는 디자인 토큰 명세(단일 출처).

## 1. 사용자 요청

> "projects/Sound1/docs/참고/nofm/정리/nofm-output-pattern-viewer.html 의 문서 테마 스타일이 내가 원하는 테마 스타일이야. html 뿐만 아니라 기타 다른 문서에서도 이 스타일을 적용할 수 있게 지침을 업데이트 해줘."

`AskUserQuestion`으로 두 모호점 해소:
- **적용 대상**: 은수님이 4종 **모두** 선택 — HTML 뷰어·아티팩트 / Mermaid 다이어그램 / Obsidian·wiki 스타일 / 디자인 토큰 명세
- **지침 위치**: **루트 전역 지침**(`docs/지침/`) — 테마가 도메인 무관 범용 스타일이므로

## 2. 목표

- 목표_1: 원본 HTML(`projects/Sound1/docs/참고/nofm/정리/nofm-output-pattern-viewer.html`, 682줄, CSS 변수 71곳)에서 **완전한 디자인 토큰**(색·타이포·간격·컴포넌트 패턴) 추출
- 목표_2: 루트 전역 지침 신설 — 토큰 명세를 **단일 출처(SSOT)**로 두고, 3개 적용 방법(HTML·Mermaid·Obsidian)이 이를 참조
- 목표_3: **HTML 뷰어·아티팩트** 적용 — `:root` CSS 변수 블록 복사-붙여넣기 스니펫 + 컴포넌트 패턴(카드·컨트롤·stats·badge)
- 목표_4: **Mermaid 다이어그램** 적용 — 팔레트를 Mermaid `themeVariables`/`classDef`에 매핑. 기존 [`작성-스타일.md §4.3`](../../../지침/일반/문서/작성-스타일.md) flowchart 정책·§4.5 노드 안전 규칙과 정합
- 목표_5: **Obsidian·wiki** 적용 — Obsidian CSS 스니펫(변수 오버라이드)으로 동일 룩 재현
- 목표_6: 원본 파일은 참조 예시로 링크(수정하지 않음)
