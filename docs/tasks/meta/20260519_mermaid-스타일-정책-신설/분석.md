- 결정_1: **정책 단일 진실 원본 = 루트 [`작성-스타일.md §4.3`](../../../지침/일반/문서/작성-스타일.md)**. mermaid-study 04 노트 §13은 정책 한 줄 명세 표 + 풀 예시 1개 (정책 본문은 루트에 jump). 선택지 (가) 채택 — 단일 진실 원본 명확성 우선
- 결정_2: **v11 `doc` 노드 권장 + fallback NOTE** — "v11 미만 환경에서는 `[/.../]` 평행사변형으로 대체 가능" 명시. 선택지 (라) 채택

## 부록: 자기 적용 시연 (정책 풀스타일 mermaid)

본 task가 신설 정책의 첫 사용 사례이므로 정책 풀스타일 mermaid 1개 포함. 본 다이어그램은 신설 정책 8요소 모두 적용. 정책 단일 진실 원본(`루트 작성-스타일.md §4.3`)과 mermaid-study 04 노트 §13의 관계를 시각화.

```mermaid
---
title: "Mermaid 스타일 정책 — 단일 진실 원본 + 참조 흐름"
config:
  theme: base
  themeVariables:
    darkMode: false
    background: "#fafafa"
    primaryColor: "#eef0f3"
    primaryTextColor: "#374151"
    primaryBorderColor: "#7a8896"
    lineColor: "#475569"
    fontFamily: "Pretendard, Apple SD Gothic Neo, sans-serif"
    fontSize: "12px"
    clusterBkg: "#fafafa"
    clusterBorder: "#cfd8dc"
    edgeLabelBackground: "#ffffff"
  flowchart:
    curve: monotoneY
    nodeSpacing: 30
    rankSpacing: 30
    padding: 12
    htmlLabels: true
---
flowchart TD
    subgraph canvas [" "]
        direction TB

        Start([정책 적용 의사 결정])
        Read("작성-스타일.md §4.3 조회<br/>(단일 진실 원본)")
        Spec[(8요소 명세<br/>frontmatter·12px·굵은선·canvas·v11 절제·고전 시작끝·사각형 0)]
        Cat[[mermaid-study 04 노트<br/>§1~§12 옵션 카탈로그]]
        ExLink[/"04 노트 §13<br/>정책 풀 예시 1개 + 한 줄 명세"/]
        Self{{본 task 자기 적용<br/>분석.md 본 다이어그램}}
        Apply@{ shape: doc, label: "신규·갱신 다이어그램<br/>풀스타일 적용" }
        Done(((정책 통일 외형<br/>· 테마 비종속 · 노드 다양성)))

        Start ==> Read ==> Spec
        Spec ==> ExLink
        Spec ==> Apply
        ExLink -. "참조 (옵션 자유)" .-> Cat
        Spec ==> Self
        Self ==> Apply ==> Done

        classDef terminal fill:#ede4d3,stroke:#9a8567,stroke-width:3px,color:#4a3d29
        classDef step     fill:#eceff3,stroke:#7a8896,stroke-width:3px,color:#374151
        classDef io       fill:#dde6ee,stroke:#6c849c,stroke-width:3px,color:#2a3f55
        classDef trigger  fill:#ecdcbb,stroke:#a07b3a,stroke-width:3px,color:#5a3e1b
        classDef core     fill:#dee6d4,stroke:#7a8f5e,stroke-width:3px,color:#3d4c2b

        class Start,Done terminal
        class Read step
        class Spec,ExLink io
        class Cat step
        class Self trigger
        class Apply core

        linkStyle default stroke-width:3px
        linkStyle 4 stroke:#7a6e8c,stroke-width:2px,stroke-dasharray:6 4
    end

    style canvas fill:#fafafa,stroke:#cfd8dc,stroke-width:1px
```

**적용된 정책 8요소 검증**:

| # | 요소 | 본 다이어그램 적용 |
|---|---|---|
| 1 | YAML frontmatter `config` | `title`·`theme:base`·`themeVariables`·`flowchart` 블록 |
| 2 | 폰트 12px | `fontSize: "12px"` |
| 3 | 굵은 선 기본 | `classDef ... stroke-width:3px` 5종 + `linkStyle default stroke-width:3px` + `==>` |
| 4 | 점선 한정 사용 | `ExLink -. "참조 (옵션 자유)" .-> Cat` 1곳 (옵션 카탈로그는 보조 참조) |
| 5 | `canvas` 서브그래프 배경 고정 | `subgraph canvas [" "]` + `darkMode:false` + `themeVariables.background` + `style canvas fill:#fafafa` |
| 6 | v11 `doc` 절제 사용 | `Apply@{ shape: doc }` 1개 (실행 산출 의미) |
| 7 | 시작·끝 고전 외형 | Start = `stadium` ([...]), Done = `double-circle` ((( ))) |
| 8 | 사각형 0개 + 외형 다양성 | stadium·rounded·cylinder·subroutine·평행사변형·hexagon·doc·double-circle 8종 |
