# 요구사항: Mermaid 스타일 정책 신설

**TL;DR**: 루트 [`docs/지침/일반/문서/작성-스타일.md`](../../../../지침/일반/문서/작성-스타일.md) §4 Mermaid 섹션에 표준 스타일 정책 8요소 신설 — YAML frontmatter `config` 블록·12px 폰트·`stroke-width:3px` 굵은 선·점선 한정·`canvas` 서브그래프 배경 고정·v11 신 노드 절제 사용·시작/끝 고전 외형·사각형 0개. 본 정책은 [`mermaid-study/docs/노트/예시/스타일정책-시안_부트로더-기동순서.md`](../../../../projects/mermaid-study/docs/노트/예시/스타일정책-시안_부트로더-기동순서.md) Rev.3로 3라운드 검증 완료된 형태. 채택 후 모든 도메인 작업의 mermaid 다이어그램 작성 시 1차 레퍼런스.

## 1. 사용자 요청

2026-05-19 세션에서 은수님이 지시한 원문 (요약):

> "루트에서 지침 업데이트를 좀 하자. mermaid로 다이어그램을 그릴 때는 mermaid-study/docs/노트/04-스타일과 테마.md의 6.2와 9 같은 스타일로 작성하게 해줘. 폰트 크기는 14px 정도로 하고. 선은 도형과 엣지 등 전부 굵음이 기본으로. 점선이 필요한 경우는 사용하도록 하고. 그리고 어느 실행되는 환경이 어떤 테마이던 영향을 받지 않게, 다이어그램 전체를 이름 없는 서브 그래프로 만들어서 배경이 있는 것 처럼 만들면 좋겠어. YAML frontmatter 방식으로 만들면 좋겠어. 노드와 모양은 v11 신 문법까지 활용하게 하고. 시작, 끝, 단계 등 전통 문법에 있는 노드 외형을 잘 활용하면 좋겠어. 너무 사각형 네모만 있는건 싫어."

3 라운드 시안 피드백을 거쳐 정책 8요소 합의 (은수님 답변 `A` = 채택):

| 라운드 | 변경 |
|---|---|
| Rev.1 (시안 초기) | 8 클래스 vivid 색 · 14px · v11 노드 3종(`bolt`·`paper-tape`·`doc`) · 3중 배경 안전장치(`themeCSS` 포함) |
| Rev.2 (1차 피드백) | 색 5 클래스 muted · **12px** (은수님 직접 조정) · v11은 `doc` 1종만 · 시작끝 `stadium`·`double-circle` 고전 외형 |
| Rev.3 (2차 피드백) | `themeCSS` 제거(옵시디언/GitHub 둘 다 `securityLevel:strict`로 차단되어 효과 없음). mermaid 측 한계 명시. 옵시디언 CSS snippet 분리 가이드 추가 |
