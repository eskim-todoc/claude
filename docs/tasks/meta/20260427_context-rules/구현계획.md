# 구현계획: 컨텍스트 절약 지침 추가

**TL;DR**: 신규 `docs/지침/일반/컨텍스트 절약 규칙.md`에 원본 §1~§5을 보존+frontmatter+TL;DR을 입혀 통합하고, CLAUDE.md·지침/README·작업 규칙 §6 인덱스를 갱신, 원본 루트 파일은 삭제. 표현은 "Task 툴" → "서브에이전트(Agent 도구)"로 정확화.

## 1. 전체 시퀀스

```
[Step 1] 위치 결정 → 지침/일반/컨텍스트 절약 규칙.md
   ↓
[Step 2] 신규 지침 작성 (frontmatter+TL;DR+원본 §1~§5)
   ↓
[Step 3] CLAUDE.md, 지침/README.md 인덱스 갱신
   ↓
[Step 4] 작업 규칙.md §6 신규 추가
   ↓
[Step 5] 원본 루트 파일 삭제
   ↓
[Step 6] 검증 — frontmatter·인덱스·원본 부재
```

## 2. 단계별 상세

### Step 1: 위치 결정

**작업**:
- 사용자가 루트에 추가한 `claude_code_context_rules.md`(Claude 응답·툴 사용 시 컨텍스트·토큰 절감 지침)을 `docs/지침/`에 통합
- 위치 후보 검토 결과: **`docs/지침/일반/컨텍스트 절약 규칙.md`** 신규로 결정

이유:
- 응답 작성·툴 사용·보고 형식 등 "응답 효율"에 관한 일반 규칙 → `일반/` 카테고리 적합
- 단일 파일을 위해 새 폴더(`효율/` 등)는 과함 (지침/ 하위 2레벨 컨벤션)
- `커뮤니케이션 규칙.md`(말투·페르소나)와 차원이 달라 별도 파일로 분리

### Step 2: 신규 지침 작성

**작업**:

- 원본 본문 보존: §1~§5 그대로
- 제거: 첫 안내 문구("이 파일은 ... `CLAUDE.md`에 그대로 병합하거나 ...") — 위치에 따라 무의미
- 추가:
  - frontmatter (name/purpose/type/applies_to/tags)
  - TL;DR (1줄 요약)
  - §2.5 NOTE — 회고 `커뮤니케이션.md` 명사구 한 줄 요약과 호환 (3줄 보고 다음에 추가)
  - §6 관련 지침·회고 링크
- 표현 보완: §3.D "Task 툴(서브에이전트)" → "서브에이전트(Agent 도구, `Explore`/`general-purpose` 등)" — Claude Code 정확한 명칭

## 3. 검증 절차

### 3.1 단계별
- 각 commit 직전 `git status` + `git diff --stat`
- 신규 지침 frontmatter 유효

### 3.2 최종
- 인덱스 3곳에 새 지침 등재 확인
- 원본 루트 파일 부재
- 다음 응답부터 새 규칙 즉시 효력 (Read offset/limit, 보고 3줄, 서브에이전트 위임 등)
