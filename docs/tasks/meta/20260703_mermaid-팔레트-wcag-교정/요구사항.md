# 요구사항: Mermaid 기본 팔레트 WCAG 교정

**TL;DR**: `작성-스타일.md §4.3.2` 기본 5색 muted 팔레트 중 3종(terminal 2.81·trigger 2.88·core 2.77)이 WCAG 1.4.11(비텍스트 3:1) 미달. hue 보존 최소 darken으로 stroke를 ≥3.2:1로 교정: `#9a8567`→`#8f7b5f`·`#a07b3a`→`#967336`·`#7a8f5e`→`#708356`. §4.3.2 표·§4.3.3 예시·§4.4 sequence/state + 문서 테마 스타일.md 다이어그램 전역 치환.

## 1. 사용자 요청

> "Mermaid 기본 팔레트 WCAG 교정 진행해"

- 목표_1: §4.3.2 기본 5색 중 미달 3종(terminal·trigger·core) stroke를 WCAG 1.4.11 3:1 이상으로 교정(hue 보존)
- 목표_2: 팔레트가 쓰인 전 위치 일관 반영 — 작성-스타일.md(§4.3.2 표·§4.3.3 풀스타일·§4.4 sequenceDiagram·stateDiagram) + 문서 테마 스타일.md 구조 다이어그램
