# 계획: Mermaid 기본 팔레트 WCAG 교정

**TL;DR**: 3색 stroke hex를 양 파일 전역 치환(Python·정밀) → §4.3.2 NOTE "교정 완료"로 갱신 → 대비 재계산·잔존 grep·Mermaid valid 검증 → 커밋. 결정론적이라 오케스트레이터 직접(폭주 가드 자기 적용).

## 1. 실행 단계 (오케스트레이터 직접)

### Step 1: 3색 stroke 전역 치환
Python으로 두 파일 정밀 치환(백틱 표기·classDef·config 모두 소문자 hex):
- `#9a8567` → `#8f7b5f` (terminal)
- `#a07b3a` → `#967336` (trigger)
- `#7a8f5e` → `#708356` (core)
대상: `작성-스타일.md`, `문서 테마 스타일.md`. tasks/·에이전트-로그 제외.

### Step 2: §4.3.2 NOTE 갱신
현재 NOTE("미달 확인·후속 예정")를 교정 완료 서술로 교체 — 교정 전후 대비값·교정일·후속 작업 링크 반영.

### Step 3: 검증
- 대비 재계산: 교정 후 5종 fill↔stroke 전부 ≥3.0:1
- grep 잔존: 구 3색 hex 0(tasks 제외)
- Mermaid 예시 렌더 valid(MCP 또는 문법 확인)

### Step 4: 이력·목록·커밋
- `작업 목록.md` 해당 행 대기→완료
- `이력 및 결과.md` 완료 요약
- 커밋

## 2. 위험 관리
| 위험 | 완화 |
|---|---|
| 치환 오검(stroke 아닌 곳) | 분석 §3 역할 확인 완료, 치환 후 diff 육안 |
| 대문자 hex 누락 | grep -i로 대문자도 확인(분석 결과 전부 소문자) |
