# 분석: Mermaid 기본 팔레트 WCAG 교정

**TL;DR**: WCAG 상대휘도 직접 계산 — 5종 중 terminal·trigger·core가 fill↔stroke 3:1 미달(2.77~2.88). hue 보존 최소 darken으로 stroke만 교정(≥3.22:1). 텍스트 color는 전부 양호(7~9:1)라 불변. 구 3색은 stroke/border 역할로만 쓰여 전역 치환 안전.

## 1. 현 상태 — 대비 실측 (WCAG 1.4.11, 목표 3:1)

| 클래스 | fill | stroke | 대비 | 판정 |
|---|---|---|---|---|
| terminal | `#ede4d3` | `#9a8567` | 2.81:1 | **FAIL** |
| step | `#eceff3` | `#7a8896` | 3.14:1 | PASS |
| io | `#dde6ee` | `#6c849c` | 3.07:1 | PASS |
| trigger | `#ecdcbb` | `#a07b3a` | 2.88:1 | **FAIL** |
| core | `#dee6d4` | `#7a8f5e` | 2.77:1 | **FAIL** |

- 텍스트 `color`↔fill 대비는 5종 전부 7.2~8.9:1 → 텍스트는 손대지 않는다.

## 2. 교정값 (hue 보존 darken, 목표 ≥3.2:1)

| 클래스 | stroke 구 → 신 | 대비 |
|---|---|---|
| terminal | `#9a8567` → `#8f7b5f` | 2.81 → 3.22:1 |
| trigger | `#a07b3a` → `#967336` | 2.88 → 3.23:1 |
| core | `#7a8f5e` → `#708356` | 2.77 → 3.23:1 |

RGB를 0.92~0.94배로 축소(명도만 낮춤, 색상 유지). muted 톤 일관 유지.

## 3. 영향 범위 (치환 위치 — grep 전수)

| 파일 | 위치 | 구 hex |
|---|---|---|
| `작성-스타일.md` | §4.3.2 표(L133·136·137) | 3색 |
| ↳ | §4.3.3 풀스타일 classDef(L191·194·195) | 3색 |
| ↳ | §4.4 sequenceDiagram noteBorder(L250·290) | trigger |
| ↳ | §4.4 sequenceDiagram activationBorder(L251·293) | core |
| ↳ | §4.4 stateDiagram classDef warn/ok(L355·356) | trigger·core |
| `문서 테마 스타일.md` | 구조 다이어그램 classDef(L195·198) | terminal·trigger |

- 3색 hex는 전부 **stroke/border 역할**로만 등장(fill·텍스트로 안 쓰임) → 전역 치환 안전.
- `문서 테마 스타일.md` 다이어그램은 `theme: warm-paper` frontmatter가 없어 기본 팔레트 사용이 정상 → 여기도 교정 대상.

## 4. 핵심 결정

- 결정_1: 미달 3종 stroke만 교정, PASS 2종·텍스트·fill 불변(최소 변경)
- 결정_2: 전역 치환(양 파일)으로 일관성 확보
- 결정_3: §4.3.2 NOTE를 "미달 확인·후속 예정"에서 "교정 완료(대비값 기재)"로 갱신
- 결정_4: 결정론적 교정이라 fan-out 없이 오케스트레이터 직접(폭주 방지 가드 §3.1 자기 적용)

## 5. 위험·제약

| 위험 | 완화 |
|---|---|
| 치환이 stroke 아닌 곳도 건드림 | grep 확인 결과 3색 전부 stroke/border 전용 — 오검 없음 |
| 교정 후 다른 대비(텍스트 등) 저하 | 텍스트는 fill 기준이라 stroke 변경과 무관, 재계산으로 확인 |
