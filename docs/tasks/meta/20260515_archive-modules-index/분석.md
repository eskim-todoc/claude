#### 정렬 정책

`모듈 현황.md` 표 정렬:

1. **1차**: 최종 업데이트 내림차순 (최근에 변경된 모듈이 위)
2. **2차** (동률): 작업 수 내림차순 (활발한 모듈 우선)
3. **3차** (동률): 모듈명 사전순

Sound1은 2026-05-14에 4 모듈 묶임 — `signalProcessing(3)` > `ble(1)` > `sync(1)` > `ui(1)` 순. 같은 작업 수면 사전순(`ble`, `sync`, `ui`).
같은 2026-05-08 4 모듈: `meta(5)` = `LED(5)` > `touch(3)` > `bootloader(1)`. `meta` vs `LED`는 사전순으로 `LED` 우선(대문자 우선).

> [!NOTE]
> ASCII 사전순 적용 시 대문자가 소문자보다 앞. Sound1 5월 8일 모듈은 `LED` → `meta` → `touch` → `bootloader` 순이 자연스럽지 않을 수 있음. 본 작업에서는 ASCII 기준(대소문자 구분 없이 사전순)으로 통일하되, Claude가 직접 작성하므로 일관성 유지.
