기존 6.1 절차 5단계 → 6단계:

```markdown
### 6.1 절차

1. `이력 및 결과.md` 작성 (1페이지 요약 — 형식은 [`문서 작성 규칙.md`](문서%20작성%20규칙.md) §3.4.2)

4. `tasks/작업 목록.md` 활성 → 완료 섹션 이동, 폴더 링크 `_archive/...`로 갱신

6. 커밋 → 사용자 승인 → `--no-ff` 병합
```
