# 구현계획: docs/ LLM 토큰 효율 향상 (Phase 1)

**TL;DR**: md 형식 유지하되 사용 패턴을 바꿔 lazy loading 가능하게 — frontmatter+TL;DR로 본문 안 읽고도 필요성 판단, 폴더 README로 폴더 단위 인덱싱. Phase 1만으로 ~30% 토큰 절감 예상. Phase 3 YAML 분리는 YAGNI로 미진행.

```

   ↓
```

## 2. 단계별 상세

### 목표 (요약)

md 형식은 유지하되 사용 패턴을 바꿔 LLM의 lazy loading을 가능하게 함. Phase 1만 적용해도 ~30% 토큰 절감 예상.

### 도입 패턴

1. **Frontmatter (YAML 메타) + 1줄 TL;DR** — 본문 안 읽고도 파일 필요성 판단 가능
2. **폴더별 README** — 폴더 단위 lazy load (CLAUDE.md 루트 표 패턴을 폴더 단위로 확장)
3. ~~산문 → YAML 분리~~ — Phase 3 (YAGNI, 미진행)

### 컨벤션 (Phase 1.1에서 §9로 정의)

#### Frontmatter 필드
- `name` (필수): 파일 제목 (한국어)
- `purpose` (필수): 한 줄 목적 (50자 이내)
- `type` (필수): `지침` / `회고` / `사용방법` / `이력` / `참고` / `tasks` / `메타`
- `applies_to` (선택): `[root]` / `[projects]` / `[Sound1]` 등 — 적용 범위 한정 시
- `tags` (선택): 검색·필터용 키워드 배열

#### TL;DR 규칙
- 첫 헤더(`# 제목`) 바로 아래 1-3줄
- 형식: `**TL;DR**: <한 줄 결론>`

#### 폴더 README 형식
- 첫 줄: 폴더 목적 한 줄
- 표: 파일 + 1줄 설명 + 사용 시점

### 3.1 단계별
- frontmatter YAML 파싱 가능 (python yaml)
