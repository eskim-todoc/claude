# 계획 — wiki 운영 지침 rules에서 제거

**TL;DR**: wiki 운영 지침 2파일을 삭제하고, 헌법·지침 전반의 wiki 운영 참조와 자동화 잔재 문구를 정리한다. Obsidian 테마는 보존. atomic commit 3개(운영 지침 제거 / docs 구조 문구 정리 / 완료 처리)로 진행하고 `claude_develop` 병합.

## Step 1 — wiki 운영 지침 2파일 삭제 + 직접 링크 제거 (+ 4단계 산출물 동봉)

- 삭제: `지침/일반/위키 반영 절차.md`, `지침/일반/위키 배경지식 조회.md` (`git rm`)
- `CLAUDE.md`: §지침 문서 표의 두 행(위키 반영 절차·위키 배경지식 조회) 삭제. §Projects 예외노트(L102)의 반영/조회 링크를 "wiki 운영은 wiki repo 자체 지침" 취지로 정리.
- `지침/README.md`: 위 두 파일 인덱스 행 삭제(있으면).
- `지침/일반/작업/4단계-프로세스.md`: L53 배경지식 조회 NOTE 제거.
- `지침/일반/문서/작성-스타일.md`: §8 Obsidian/wiki 콘텐츠 작성 절 제거(L497~527) — wiki 콘텐츠 작성 컨벤션은 wiki 자체 지침으로.
- 동봉: 요구사항·분석·계획·이력.

## Step 2 — docs 구조의 wiki 의존 문구 정리

자동 동기화 잔재를 걷어내고 rules 자립적으로 재서술.

- `지침/작업 규칙.md`: 마스터 체크리스트의 "사용방법·참고는 Wiki Vault로 이전" 등 wiki 의존 문구 정리.
- `CLAUDE.md`: L19 Layout 주석의 "사용방법·참고는 Wiki Vault" 정리.
- `지침/일반/프로젝트 초기 세팅.md`: L93·L167 사용방법·참고 Wiki Vault 문구 정리.
- `지침/일반/문서/폴더-구조.md`: L33·L44·L50·L60·L205 "Wiki Vault로 이전"·"Wiki sync 진입판단용" 정리.
- `지침/일반/문서 작성 규칙.md`: L55·L57 `[사용방법]`·`[참고]`→Wiki 매핑 정리.
- `지침/일반/작업/완료처리.md`: L18 "Wiki 등 외부 sync 진입판단용" → "모듈 헬스 스냅샷"으로 목적 재서술.
- `docs/tasks/모듈 현황.md`: TL;DR·운영메모의 "Wiki sync 진입판단용" → 모듈 헬스 스냅샷.
- `docs/tasks/README.md`: "Wiki sync" 문구 정리(있으면).
- **slack 사용법 링크**(`CLAUDE.md` L94·L158): 사용법이 형제 wiki repo에 있다는 최소 정보만 유지(경로 안내). 도구 사용처 안내라 정보 가치 유지.

> [!NOTE]
> **"사용방법·참고"의 새 배치 방침**: 자동 이전 정책은 폐지하되, 영속 참고성 지식은 여전히 wiki가 자연스러운 귀착지다. docs 구조 문서에는 "영속 참고 지식은 별도 wiki repo로 (은수님이 취합해 수동 반영)" 정도의 한 줄 서술만 남기고, 이전 절차·트리거는 두지 않는다.

## Step 3 — 검증·완료 처리

- 삭제된 파일을 가리키는 깨진 링크 0 확인(`grep`으로 `위키 반영 절차`·`위키 배경지식 조회` 잔존 검색).
- Obsidian 테마 3트랙 중 Obsidian 트랙 보존 확인.
- `docs/tasks/meta/작업 목록.md`·`docs/tasks/모듈 현황.md` 등재, `이력 및 결과.md` 완료 요약.
- `claude_develop` 병합(`--no-ff`) + push.

`테마/Obsidian.md`, `문서 테마 스타일.md`의 Obsidian 트랙, 테마 인덱스(CLAUDE.md·README) 모두 **유지**.
