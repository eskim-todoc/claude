# 요구사항

**TL;DR**: 루트(`E:\Claude`)부터 프로젝트(`projects/*`)까지 모든 문서를 지침에 맞게 검토하고, 부합 안 되면 업데이트, 문서 간 링크가 깨지지 않게 정합성을 보장한다.

## 1. 사용자 요청

사용자 원문:

> "루트 폴더부터 프로젝트 폴더까지, 작성된 문서들 쫙 검토하고 지침에 맞게 구성됐는지 봐. 안되어 있으면 업데이트 해주고. 링크 깨지는거 없게 문서간 링크 잘 연결해주고."
>
> "지금부터 할게 많아서 너한테 일 시켜놓겠다" — clarifying question 없이 합리적 판단으로 끝까지 진행 지시.

사용자가 일괄 승인을 명시했으므로 `작업 진행 규칙` §5 적용, 단계 ④ 직진.

## 2. 목표

### 검토 범위 (read-only 분석)
- 루트 `CLAUDE.md`
- 루트 `docs/` 전체 (지침/, 회고/, 사용방법/, tasks/)
- 각 `projects/<name>/CLAUDE.md`
- 각 `projects/<name>/docs/` 전체

### 수정 범위 (필요 시 업데이트)
- 검토에서 발견된 모든 불일치/링크 오류 — 단, 프로젝트 repo는 별도 git scope이므로 **루트 repo와 프로젝트 repo 커밋 분리** 필요 (지침 §6 Git 스코프).

### 검토 기준 (지침 부합성 체크)

| 요구사항_1 | 루트 `CLAUDE.md`가 실제 디렉토리(특히 `projects/`) 구조와 일치 | `CLAUDE.md` Layout/Projects 섹션 |

### 수정 방침
- 불일치는 **있는 그대로 보고 + 수정안 제시**, 큰 수정(문서 신설/구조 재배치)은 사용자 승인 후 적용
- 단순 누락(인덱스 행 추가, 깨진 링크 수정, 경로 인코딩 누락)은 단계 ④ 진입 시 일괄 수정
- 프로젝트 repo 수정은 루트 repo 작업과 분리 — 본 task는 루트 repo 스코프이며, 프로젝트 repo가 손대야 하면 별도 task로 분기
