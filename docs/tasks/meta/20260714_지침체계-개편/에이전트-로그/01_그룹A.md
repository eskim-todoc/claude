## 특이사항

- `작업 진행 규칙.md` §2 표: 헤더 `| 파일 | 내용 | maturity |` → `| 파일 | 내용 |`, 구분선 3열→2열, 6개 데이터 행에서 각 `| core |` 셀 삭제.
- `폴더-구조.md`는 산문 언급이 가장 많았음. §2 "회고 흡수분 (`maturity: experimental`)" 구절은 괄호째 삭제(문장 자연스러움 유지). "frontmatter에 `maturity: core | stable | experimental` 명시" 문장은 "frontmatter 필수 필드를 명시"로 재작성(문맥·링크 참조는 보존). §3 "(4개 양식 모두 maturity: core)" 괄호는 통째 삭제.
- `작성-스타일.md` §7.1~7.4는 헤딩 텍스트·날짜 `(YYYY-MM-DD)` 전부 보존, 말미의 ` *(maturity: ...)*` 마커만 삭제.
- `작성 규칙.md` TL;DR의 `frontmatter(name·purpose·type·maturity·tags)` → `frontmatter(name·purpose·type·tags)`로 필드 나열에서만 제거.
- 나머지 5개 파일(작업 규칙.md/네이밍 컨벤션.md/구현 패턴.md/분석·디버깅 규칙.md/컨텍스트 절약 규칙.md)은 frontmatter `maturity:` 줄 삭제만 필요, 본문에는 maturity 언급 없었음.
- 담당 범위 밖 파일(예: `지침/README.md`, `지침/문서/메타-frontmatter.md`, `지침/일반/작업/4단계-프로세스.md`, `지침/Git/워크플로우.md` 등)은 여전히 maturity 언급이 남아있으나 이는 다른 그룹 담당으로 손대지 않음.
