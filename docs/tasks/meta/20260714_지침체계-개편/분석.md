## 3. 가설·선택지

### 3.1 가설 (root cause·디버깅)

오케스트레이션 문서 미작성의 root cause — 3개 가설 cross-check:

- 가설_1 (권한): 서브에이전트가 Write/Edit 권한이 없어 못 남긴다 → **기각**. general-purpose는 `*`(전체 도구) 보유([`활용.md`](../../../../지침/서브에이전트/활용.md) L85-89), 위반 표본의 노드도 general-purpose였음. 설정에 Task/Write deny 없음.
- 가설_2 (상기 실패): CLAUDE.md core 자동주입에 로그 요구가 없어 세션이 인지 못 함 → **성립**. §5는 활용·오케스트레이션 2파일만 링크, 로그 구조.md 미링크.
- 가설_3 (프롬프트 누락): 오케스트레이터가 위임 프롬프트에 "결과를 로그 파일에 Write하라"를 안 넣어 노드가 안 남김 → **성립**. 위반 표본은 941줄 반환값을 오케가 직접 받아 첨부 JSON으로 합침(fan-in 예산도 위반).
- **결론**: 가설_2+가설_3 복합. 권한(가설_1) 아님.

### 3.2 선택지 (설계 결정)

**선택지 A — SSH 키 배선 방식**

| 선택지 | 장점 | 단점 |
|---|---|---|
| repo-local `core.sshCommand` (각 repo) | repo별 독립, credentials 키 명시 참조, 홈 오염 없음 | 13개 repo 반복 설정(스크립트로 일괄), 절대경로 박힘 |
| 전역 `~/.ssh/config` Host alias | 1회 설정으로 전 repo 커버 | 사용자 홈 종속(repo에 안 담김), 이식성 문서화 필요 |

→ **repo-local `core.sshCommand` 채택**(위임_3). 각 repo `.git/config`에 credentials 키 절대경로 지정, 일괄 스크립트. 이식성은 문서화로 보완.

**선택지 B — 검증 파일 구조**

| 선택지 | 장점 | 단점 |
|---|---|---|
| 독립 검증파일 4개 (사용자 확정) | 단계별 검증 추적 명확, 오케 문서화 요구와 정합 | 파일 수 8개(4산출+4검증) |
| 단일 검증.md 누적 | 파일 적음 | 단계 경계 흐림 (사용자 기각) |

→ **독립 4파일 확정**. 명명: `요구사항-검증.md` / `분석-검증.md` / `계획-검증.md` / `구현-검증.md`. 신규 `검증.md` 양식 1개 추가.

## 4. 핵심 결정

- 결정_1 (maturity 제거 순서): SSOT(`메타-frontmatter.md`) → 인덱스(README 3종) → 진입점(CLAUDE.md) → 기계적 33파일 순. 인라인 선정 기준은 **"위반 시 즉시 중단되는 절대 준수 규칙"**으로 대체 서술(grep 자동추출 근거 삭제).
- 결정_2 (8단계 정의): 검증을 정식 단계로 승격하되 성격은 **자체 검증**(지침준수·논리정합·근거검증 3축 계승). 사용자 승인은 계획검증 후 구현 진입 전 **1회 유지**. 핵심 파일 `작업-프로세스.md`로 개명.
- 결정_3 (검증 독립 파일화): 현행 "별도 파일 분리 금지"(4단계-프로세스 §3 L129) 규정을 **반전** — 각 산출물 말미 자체검토 섹션 제거, `<단계>-검증.md` 독립 파일로. `이력 및 결과.md` 진척표 8행.
- 결정_4 (검증-용어 충돌 해소): 오케스트레이션.md의 기존 "④구현후 검증"(빌드/테스트/링크체크·검증 루프)은 신규 8단계의 **⑧ 구현/처리 검증에 흡수**. 나머지 3개 검증(②④⑥ 자리)은 신규 자체검증으로 정의.
- 결정_5 (SSH 배선): repo-local `core.sshCommand` + credentials 키 절대경로. GitHub 11 + GitLab 1 구분(GitLab은 키 등록 확인 필요).
- 결정_6 (오케 강제 3중): ① CLAUDE.md §5 core에 "2노드+ fan-out 시 `에이전트-로그/` 필수" + 로그 구조.md 링크 추가 ② 위임 프롬프트 표준 문구 신설(로그 구조.md에) ③ 완료처리.md에 로그 폴더 존재 점검 항목 추가.
