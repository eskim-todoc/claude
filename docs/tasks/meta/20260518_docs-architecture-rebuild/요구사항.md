### 1.3 자율 위임 범위
사용자가 "자리 비울거니까 알아서 해줘"라고 명시 → 다음 결정 메인 agent 자율:

- maturity 라벨 분류 (→ core 8·stable 14·experimental 13)
- 거대 파일 분할 후 신 파일명·라인 분배 (→ 서브에이전트 매핑)
- SessionStart Hook 명령 형태
- commit 단위·메시지·브랜치 전략 (`claude_feature_docs-rebuild` 신규 생성)
- 검증 절차

위임 범위 밖 (사용자 결정 영역):

## 2. 4가지 거시 의문 요약 (사용자 원문 기반)

1. **회고 따로 관리 의미?** — 검증되면 즉시 지침이 되어야 하지 않나? → **통합 결정** (옵션 X 채택)
2. **분할 시 새 세션 적용?** — 반드시 지켜야 할 지침마저 세분화되면 적용 보장될까? → **CLAUDE.md 핵심 인라인 + SessionStart Hook 결정** (Y-1·Y-2 채택)
3. **list ≈ _modules?** — 사실상 같은 개념 아닌가? → **통합 불가 (차원 다름) — 명명·TL;DR 명확화** (Z-3 채택)
4. **작업 폴더 가시성·plans·5파일?** — 폴더 날짜 표시 X, plans 임시 보관, 5파일 표준화 → **날짜 prefix 채택(Z-1), plans 기각, 5파일은 4파일 유지 결정** (구현 = 코드, 분석 없이 계획 불가)
