# 계획: docs 아키텍처 근본 재설계 (7단계 atomic commit)

**TL;DR**: Package C 풀 리팩토링을 7개 atomic commit으로 분해. 단계 1(폴더+산출물) → 단계 2(거대 파일 분할 P1·P2) → 단계 3(회고 흡수 + maturity 라벨 + 회고 폴더 폐지) → 단계 4(작업 폴더 날짜 prefix + 명명 변경 + cross-link) → 단계 5(CLAUDE.md 핵심 인라인 + 새 구조 반영) → 단계 6(SessionStart Hook) → 단계 7(이력 및 결과 + 모듈 현황 최종 갱신). 각 단계 commit은 atomic·revertable. 영향 51+ 파일·80+ 라인. 브랜치 `claude_feature_docs-rebuild` 격리.

## 1. 전체 시퀀스

```
[Step 1] 폴더 rename + 요구사항·계획 산출물        ← (지금 완료 직전)
   ↓
[Step 2] 거대 파일 분할 (P1·P2)                   ← 분할이 먼저, 회고가 분할된 하위 파일에 흡수
   ↓
[Step 3] 회고 35항목 → 지침 흡수 + maturity 라벨 + 회고 폴더 폐지
   ↓
[Step 4] 작업 폴더 날짜 prefix (12개) + 명명 변경 (_modules·이력) + cross-link 갱신
   ↓
[Step 5] CLAUDE.md 핵심 인라인 (Y-1) + 새 구조 반영
   ↓
[Step 6] SessionStart Hook (Y-2)
   ↓
[Step 7] 이력 및 결과.md + 모듈 현황.md 최종 갱신
```

## 2. 단계별 상세

### Step 1: 작업 폴더 + 산출물 (현 단계)
**작업**
- `git mv` 실패 → 일반 `mv`로 폴더 rename: `guideline-segmentation-analysis` → `20260518_docs-architecture-rebuild`
- 요구사항.md 작성
- 계획.md 작성 (본 문서)

**영향 파일**: 신규 2 + 이동 폴더 (이전 두 파일 분석.md·재설계-아이디어.md 자동 이동)
**검증**: `ls docs/tasks/meta/20260518_docs-architecture-rebuild/` 4개 파일 (요구·분석·계획·재설계-아이디어)
**commit 메시지**: `feat(meta): 20260518_docs-architecture-rebuild 작업 폴더 + 요구사항·계획 산출물 (Package C 실행 진입)`

### Step 2: 거대 파일 분할 (P1·P2)
**작업** (서브에이전트 C 매핑 그대로 적용)
- **P1**: `docs/지침/일반/문서 작성 규칙.md` (494줄·14섹션) → 분할
  - `지침/일반/문서 작성 규칙.md` (인덱스, ~45줄)
  - `지침/일반/문서/폴더-구조.md` (~130줄)
  - `지침/일반/문서/메타-frontmatter.md` (~110줄)
  - `지침/일반/문서/작성-스타일.md` (~145줄)
- **P2**: `docs/지침/일반/작업 진행 규칙.md` (224줄·9섹션) → 분할
  - `지침/일반/작업 진행 규칙.md` (인덱스, ~35줄)
  - `지침/일반/작업/4단계-프로세스.md` (~95줄)
  - `지침/일반/작업/완료처리.md` (~20줄)
- 분할 시 신 명명 반영(`모듈 현황.md`·`이력 및 결과.md`) — 본 단계에서 신 이름으로 작성 (실제 rename은 Step 4)
- 분할 파일 내부 cross-link 갱신 (인덱스 ↔ 하위 파일)

**영향 파일**: 신규 5 + 기존 2 갱신
**검증**: 새 7파일 라인 합 ~580줄 (기존 718줄 → 분할 후 590줄, 인덱스화로 축소). 모든 섹션 텍스트가 어느 하나에는 존재 (drop 없음)
**commit 메시지**: `refactor(지침): 문서 작성 규칙·작업 진행 규칙 인덱스+하위 분할 (P1·P2)`

### Step 3: 회고 → 지침 흡수 + maturity + 회고 폐지
**작업** (서브에이전트 A 매핑 그대로 적용)
- 35개 회고 항목을 지정 지침 파일·섹션에 흡수
- 각 흡수 항목·기존 지침 항목 모두에 `maturity: core | stable | experimental` 라벨 부여
  - 라벨 위치: 섹션 헤더 옆 (예: `## 항목 제목 {maturity: core}`) 또는 frontmatter `maturity_default`
  - **결정**: 섹션 단위 라벨이 정확하므로 헤더 뒤 인라인 마커 `*(maturity: core)*` 사용 — 마크다운 호환·grep 친화
- 흡수 완료 후 `docs/회고/` 폴더 통째로 삭제 (`git rm -r` 시도 → untracked인 분석.md·재설계-아이디어.md 무관)
- `docs/회고/` 참조하던 곳들은 Step 4 cross-link 갱신에서 신 위치로 redirect (CLAUDE.md 회고 섹션은 Step 5에서 제거)

**영향 파일**: 회고 6 삭제, 지침 16 중 다수 갱신
**검증**: 회고 35항목 모두 지침 어딘가에 존재 (grep으로 키워드 확인). 회고 폴더 부재
**commit 메시지**: `refactor(지침): 회고 35항목 지침 흡수 + maturity 라벨 + 회고 폴더 폐지 (옵션 X)`

### Step 4: 폴더 prefix + 명명 변경 + cross-link
**작업**
- **폴더 날짜 prefix** (Z-1): 12개 작업 폴더 rename
  - 시작일 prefix는 `_modules.md` 작업 상세 섹션의 완료일 사용
  - "—" 완료일(`wiki-bootstrap`)은 본 작업 진행일(2026-05-18)로 처리하거나 prefix 생략 — **결정**: 미시작은 작업 슬러그만 유지 (prefix 없음 OK, 추후 시작 시 부여)
  - 본 작업 폴더(`20260518_docs-architecture-rebuild`)는 이미 prefix 적용됨
- **명명 변경**:
  - `docs/tasks/_modules.md` → `docs/tasks/모듈 현황.md` (`git mv` 또는 `mv`)
  - 모든 작업 폴더의 `이력.md` → `이력 및 결과.md` (현 12 폴더 중 일부에만 존재 — `Glob` + `git mv`)
- **cross-link 일괄 갱신** (서브에이전트 B 매핑):
  - `_modules.md` 또는 `_modules` 참조 7파일 → `모듈 현황.md`로
  - `이력.md` 참조 22+파일 → `이력 및 결과.md`
  - `회고/` 경로 참조 → 지침 신 위치
  - `meta/<작업>/` 경로 참조 → `meta/<날짜>_<작업>/`

**영향 파일**: 12 폴더 rename + 1 파일 rename + 갱신 51+ 파일
**검증**: `grep -r "_modules\.md"`·`grep -r "이력\.md"`·`grep -r "docs/회고/"` 결과 0 (또는 사라진 컨텍스트의 잔류만)
**commit 메시지**: `refactor(tasks): 폴더 날짜 prefix + 명명 변경(_modules·이력) + cross-link 일괄 갱신 (Z-1·명명)`

### Step 5: CLAUDE.md 핵심 인라인 + 새 구조 반영
**작업** (Y-1)
- 루트 `CLAUDE.md` 갱신:
  - `## 회고` 섹션 전체 제거 (회고 폴더 폐지)
  - `## 지침 문서` 표 갱신: 새 분할 파일 4개 추가, 거대 파일 인덱스화 반영
  - `## 핵심 지침 (자동 적용)` 신설 — `maturity: core` 라벨 항목 풀텍스트 인라인 (~50~80줄)
    - 후보: 존댓말, 세션 시작 Read 강제, 명령 모호 시 질문, 4단계 프로세스 요지, 서브에이전트 활용 원칙, 부사수 페르소나, 문서 선행 작성
  - `## 메모리` 섹션의 회고 참조 제거 + 신 위치 안내
- 누락 행 보강 (분석.md의 P3): `계획 모드 자동 진입.md` 추가 (분할 후 인덱스 표에 한 줄)

**영향 파일**: 1 (CLAUDE.md)
**검증**: 새 세션 시뮬레이션 — CLAUDE.md만 자동 주입돼도 핵심 지침이 인지되는지 자체 점검
**commit 메시지**: `refactor(meta): 루트 CLAUDE.md 핵심 지침 인라인 + 회고 섹션 제거 + 분할 반영 (Y-1)`

### Step 6: SessionStart Hook 설정
**작업** (Y-2)
- `.claude/settings.json` 확인 (현 hook 설정 검토)
- SessionStart Hook 추가:
  - 명령: `cat E:\Claude\CLAUDE.md` 결과를 자동 주입
  - 또는 더 가벼운: `Get-Content "E:\Claude\CLAUDE.md" | Select-Object -First 50` (핵심 인라인 부분만)
  - **결정 위임**: CLAUDE.md 자체가 이미 자동 주입되므로 Hook은 "핵심 지침 강조" 메시지만 출력 — 토큰 절약
  - 예: `echo "[SessionStart] 루트 지침 확인: maturity:core 항목 ($(grep -c 'maturity: core' E:/Claude/CLAUDE.md)) — 위반 시 즉시 멈춤"`

**영향 파일**: 1 (`.claude/settings.json`)
**검증**: 새 세션에서 hook 메시지 출력 확인 (테스트 세션 또는 자체 점검)
**commit 메시지**: `feat(hook): SessionStart hook으로 핵심 지침 자동 강조 (Y-2)`

### Step 7: 이력 및 결과 + 모듈 현황 최종 갱신
**작업**
- `이력 및 결과.md` 작성 (본 작업 폴더):
  - 시계열 로그 (각 Step 시작·종료 시간·요약)
  - 완료 요약 섹션 (변경 통계·검증 결과·미해결 항목)
- `docs/tasks/모듈 현황.md` 갱신:
  - meta 모듈 최종 업데이트 → 2026-05-18
  - 최근 작업 → 본 작업 링크
  - 작업 수 +1 (12 → 13)
  - 작업 상세 섹션에 본 작업 행 추가

**영향 파일**: 신규 1 + 갱신 1
**검증**: 모든 수용 기준(요구사항.md §3) 충족 확인. 미해결 항목 명시
**commit 메시지**: `docs(meta): docs-architecture-rebuild 작업 완료 — 이력 및 결과·모듈 현황 갱신`

## 3. 검증 절차 (각 단계 + 최종)

### 3.1 단계별
- 각 commit 직전 `git status` + `git diff --stat` 확인
- 영향 파일이 계획 범위 내인지 확인 (오버런 방지)

### 3.2 최종 (Step 7 후)
- **Broken link 검사**: `grep -r "_modules\.md"`·`grep -r "회고/"`·`grep -r "이력\.md"`·`grep -r "meta/<구 작업명>"` → 모두 0 또는 의도된 잔류만
- **Maturity 라벨 누락 검사**: `grep -L "maturity:" docs/지침/**/*.md` → 0 (또는 인덱스 파일만)
- **수용 기준 체크**: 요구사항.md §3 전 항목 ✓
- **회귀 시뮬레이션**: 새 Claude 세션 시작 시 CLAUDE.md만 자동 주입되어도 핵심 지침 인지되는지 확인 (자체)

## 4. 위험 관리

| 위험 | 가능성 | 영향 | 완화 |
|---|---|---|---|
| 분할된 파일 cross-link 누락 | 중 | 중 | Step 4에서 grep 일괄 검색·갱신, 최종 검증 단계 |
| 회고 흡수 시 중복 텍스트 누적 | 중 | 낮음 | 흡수 매핑 표 따라 진행, 동일 내용은 기존 우선 |
| 작업 폴더 rename 시 cross-link 누락 | 중 | 중 | 서브에이전트 B 매핑 + Step 4 grep |
| CLAUDE.md 인라인 분량 과다 | 낮음 | 중 | maturity: core 항목만 (~50~80줄 목표) |
| SessionStart Hook이 환경 의존 | 중 | 낮음 | 가벼운 메시지만 출력, 실패 시 graceful degrade |
| 거대 변경으로 develop 오염 | 낮음 | 높음 | feature 브랜치 격리, merge는 사용자 검토 후 |
| _modules.md 갱신이 작업 도중에 일어남 | 낮음 | 중 | Step 7에서 한 번에 갱신, 중간엔 손대지 않음 |
