# tasks (작업 스코프)

진행 중·완료된 작업의 폴더 모음. 작업 레지스트리는 [`list.md`](list.md), 폴더 컨벤션은 [`../지침/일반/문서 작성 규칙.md`](../지침/일반/문서%20작성%20규칙.md) §3·§4 참조.

| 항목 | 위치 | 용도 |
|---|---|---|
| **레지스트리** | [`list.md`](list.md) | 모든 작업의 활성/완료 상태·태그·연계 표 (항상 먼저 조회) |
| 활성 작업 | `<모듈>/<작업슬러그>/` | 진행 중 작업 (요구사항·분석·구현계획·진행상황) |
| 완료 작업 | `_archive/<모듈>/<작업슬러그>/` | 완료된 작업 + `이력.md` (1페이지 요약) |

## 폴더 구조

```
tasks/
├── list.md                       ← 항상 먼저 조회 (활성/완료 상태)
├── <모듈>/<작업슬러그>/            활성 (요구사항·분석·구현계획·진행상황)
└── _archive/<모듈>/<작업슬러그>/   완료 (+ 이력.md)
```

## 새 작업 시작 시

1. [`list.md`](list.md) 활성 섹션 조회 → 관련 작업 있으면 사용자에게 이어갈지 확인
2. 신규 폴더 `<모듈>/<작업슬러그>/` 생성, `요구사항·분석·구현계획.md` 작성
3. `list.md` 활성 섹션에 등재 + 갱신 이력에 한 줄

## 완료 처리 (`작업 끝났어. 마무리해` 시그널 시)

1. `이력.md` 작성 (1페이지 요약, 형식은 문서 작성 규칙.md §3.4.2)
2. `git mv` → `_archive/<모듈>/<작업>/`
3. `list.md` 활성 → 완료 섹션 이동, 폴더 링크 갱신
4. 커밋 → 사용자 승인 → `--no-ff` 병합
