# tasks (루트 작업 스코프)

**TL;DR**: 루트(`E:\Claude`) 스코프의 모든 작업(활성·완료) 폴더 모음. Task α (2026-05-15)부터 archive 폐지 — 작업 폴더는 완료 후에도 위치 영구, [`작업 목록.md`](작업 목록.md)의 `상태` 컬럼으로 식별. `이력 및 결과.md`가 진행상황·이력을 통합. 컨벤션은 [`../지침/일반/문서 작성 규칙.md §3·§4`](../지침/일반/문서%20작성%20규칙.md).

| 항목 | 위치 | 용도 |
|---|---|---|
| **레지스트리** | [`작업 목록.md`](작업 목록.md) | 모든 작업의 상태·태그·연계 단일 표 (항상 먼저 조회) |
| **모듈 인덱스** | [`모듈 현황.md`](모듈 현황.md) | 모듈별 최종 업데이트 (Wiki sync 진입판단용) |
| 작업 폴더 | `<모듈>/<작업슬러그>/` | 4단계 산출물(`요구사항.md`·`분석.md`·`계획.md`·`이력 및 결과.md`). 활성·완료 무관 영구 위치 |

## 폴더 구조

```
tasks/
├── 작업 목록.md                       ← 단일 표 (상태 컬럼으로 활성/완료 식별)
├── 모듈 현황.md                   ← 모듈 인덱스 (Wiki sync 진입판단용)
└── <모듈>/<작업슬러그>/          요구사항·분석·계획·이력 (영구 위치)
```

## 새 작업 시작 시

1. [`작업 목록.md`](작업 목록.md) 조회 → 관련 작업 있으면 사용자에게 이어갈지 확인
2. 신규 폴더 `<모듈>/<작업슬러그>/` 생성, 4단계 산출물 작성 (루트 [`작업 진행 규칙.md`](../지침/일반/작업%20진행%20규칙.md))
3. `작업 목록.md` 작업 목록에 행 추가 (상태=`진행`) + 갱신 이력에 한 줄
4. `이력 및 결과.md`를 단계 ① 시작과 동시에 생성 (시계열 로그 누적)

## 완료 처리 (사용자 *"작업 끝났어. 마무리해"* 시그널)

1. `이력 및 결과.md`에 **완료 요약 섹션 추가** (시계열 로그는 진행 중 누적되어 이미 존재)
2. `작업 목록.md`의 해당 행 `상태`를 `완료`로 변경 + `완료일` 기록
3. `모듈 현황.md` 갱신 — 모듈 인덱스에 작업 반영
4. 커밋 → 사용자 승인 → `--no-ff` 병합

> [!NOTE]
> Task α (2026-05-15)부터 **작업 폴더는 위치 영구** (`_archive/` 폴더 폐지). 외부 링크 안정성 + 폴더 이동 비용 0. 활성/완료 식별은 `작업 목록.md`의 `상태` 컬럼으로.
