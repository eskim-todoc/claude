## 4. 링크 재작성 규칙

### 4.1 Markdown 링크 URL 인코딩
- 한글: **raw로 유지** (예: `지침/일반/문서%20작성%20규칙.md`)
- 공백: `%20`으로 인코딩
- 특수문자 `·`, `,` 등: raw로 유지 (기존 컨벤션 따름)

### 4.2 상대 경로 원칙
- **같은 폴더**: 파일명만 (예: `브랜치, 병합 규칙.md` → `워크플로우.md`)
- **자식 폴더**: `하위폴더/파일명`
- **부모·형제**: `../형제폴더/파일명` 
- **CLAUDE.md → docs/**: `docs/카테고리/.../파일명`

### 4.3 예시 (`지침/작업 규칙.md` 기준)

| 기존 링크 | 신규 링크 |
|---|---|
| `[지침]%20[일반]%20커뮤니케이션%20규칙.md` | `일반/커뮤니케이션%20규칙.md` |

| 위험 | 영향 | 대응 |
