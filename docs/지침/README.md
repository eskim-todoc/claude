# 지침 (Policies & Standards)

작업 시 준수해야 할 전역 규칙·컨벤션·검증 체크리스트. 프로젝트별 특화 지침은 `projects/<name>/docs/지침/`에서 관리 (충돌 시 프로젝트 우선).

| 카테고리 | 파일 | 목적 | 사용 시점 |
|---|---|---|---|
| **마스터** | [`작업 규칙.md`](작업%20규칙.md) | 전체 체크리스트 (커뮤니케이션·문서·코딩·Git) | 모든 작업 시작 시 |
| **일반** | [`일반/문서 작성 규칙.md`](일반/문서%20작성%20규칙.md) | md 포맷·폴더 구조·파일명·frontmatter 컨벤션 | 문서 작성 시 |
|  | [`일반/커뮤니케이션 규칙.md`](일반/커뮤니케이션%20규칙.md) | 존댓말, 응답 형식 | 모든 응답 |
|  | [`일반/컨텍스트 절약 규칙.md`](일반/컨텍스트%20절약%20규칙.md) | 응답·툴 출력 압축, 보고 형식 | 모든 응답·툴 사용 |
| **Git** | [`Git/워크플로우.md`](Git/워크플로우.md) | 브랜치 모델, 병합 절차 (다이어그램 포함) | Git 작업 시작 전 |
|  | [`Git/브랜치, 병합 규칙.md`](Git/브랜치,%20병합%20규칙.md) | 브랜치 명명, Identity 설정 | 브랜치·커밋 시 |
| **코딩** | [`코딩/작업 규칙.md`](코딩/작업%20규칙.md) | 문서 선행, 구현 승인 | 코딩 작업 시작 시 |
|  | [`코딩/네이밍 컨벤션.md`](코딩/네이밍%20컨벤션.md) | C 변수/함수/매크로/타입 네이밍 | C 코드 작성 시 |
|  | [`코딩/분석·디버깅 규칙.md`](코딩/분석·디버깅%20규칙.md) | 호출 경로 검증, 가설 검증 (실사례 포함) | 디버깅·회귀 fix 시 |

> [!NOTE]
> 새 지침 추가 시 이 표에도 반드시 행을 추가한다. 충분히 안정화된 회고는 [`docs/회고/`](../회고/)에서 본 지침으로 승격될 수 있다 — 절차는 `회고/README.md` 참조.

> [!TIP]
> 각 파일 상단의 `**TL;DR**:`만 읽어도 핵심 결정을 알 수 있다 (frontmatter+TL;DR 컨벤션은 [`일반/문서 작성 규칙.md §9`](일반/문서%20작성%20규칙.md#9-문서-메타데이터-frontmatter--tldr--폴더-readme)).
