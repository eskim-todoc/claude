# 작업 완료 처리

**TL;DR**: 사용자 "작업 끝났어" 시그널 수신 시 (1) `이력 및 결과.md` 완료 요약 추가, (2) `list.md` 상태 컬럼을 `완료`로 + 완료일 기록, (3) `모듈 현황.md` 모듈 행 갱신(최종 업데이트·최근 작업·작업 수), (4) 커밋 → 사용자 승인 → `--no-ff` 병합. archive 폴더 폐지(2026-05-15~) — 작업 폴더 위치 영구 유지.

## 1. 절차

1. **`이력 및 결과.md` 완료 요약 섹션 추가** — 시계열 로그는 진행 중 누적되어 이미 존재. 형식은 [`../문서/폴더-구조.md §4.2`](../문서/폴더-구조.md)
2. **`tasks/list.md` 갱신** — 해당 행의 `상태` 컬럼을 `완료`로 변경 + `완료일` 기록
3. **`tasks/모듈 현황.md` 갱신** — 해당 모듈 행의 `최종 업데이트`(완료일)·`최근 작업`(본 작업 폴더 링크)·`작업 수`(+1) 갱신. 신규 모듈이면 행 추가. 정렬 재조정(최종 업데이트 내림차순 → 작업 수 내림차순 → 모듈명 사전순). 본 파일이 없으면 새로 생성. 본 인덱스는 Wiki 등 외부 sync 진입판단용
4. **커밋 → 사용자 승인 → `--no-ff` 병합**

> [!NOTE]
> 2026-05-15 Task α부터 **작업 폴더는 완료 후에도 `tasks/<모듈>/<작업>/` 그대로 유지** (`_archive/` 폴더 폐지). 외부 링크 안정성 + 폴더 이동 비용 0. 활성/완료 식별은 `list.md`의 `상태` 컬럼으로.

## 2. 트리거

- 사용자 *"작업 끝났어. 마무리해"* 류 시그널
- 또는 사용자가 검수 후 명시 승인
