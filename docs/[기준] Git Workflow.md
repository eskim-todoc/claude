# Git Workflow

## 1. 브랜치 모델 개요

```
  main ──────────●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━●━━━━━━━━━━▶  릴리즈 전용
                 │                                 ▲
                 │                                 │ (사용자 승인)
                 ▼                                 │
  claude_main ───●━━━━━●━━━━━━━━━━━━━━━━━━━━●━━━━━━●━━━━━━━━━━▶  안정 브랜치
                 │     ▲                    ▲      ▲
                 │     │ (hotfix)           │      │
                 │     │                    │      │ (안정 병합)
                 ▼     │                    │      │
  claude_develop ●━━━━━┿━━━━●━━━━━━━●━━━━━━●━━━━━━━●━━━━━━━━━━▶  개발 브랜치
                       │    │       ▲      ▲
                       │    │       │      │
                       │    ▼       │      │ (feature 병합)
                       │    feature_A      │
                       │            feature_B
                       │
                       hotfix
```

### 브랜치 역할

| 브랜치 | 용도 | 수명 |
|:---|:---|:---|
| `main` | 릴리즈 전용. **사용자만** 직접 관리 | 영구 |
| `claude_main` | Claude 측 안정 브랜치 | 영구 |
| `claude_develop` | 지속적 개발 통합 | 영구 |
| `claude_feature_*` | 개별 기능 구현/수정 | 임시 (병합 후 삭제) |
| `claude_hotfix` | 긴급 수정 | 임시 (병합 후 삭제) |

## 2. 기능 개발 플로우

일반적인 기능 개발 시 따르는 절차입니다.

```
  claude_develop ━━━━●━━━━━━━━━━━━━━━━━━━━━●━━━━━━━▶
                     │                     ▲
                     │ branch              │ merge --no-ff
                     │                     │ (사용자 승인 후)
                     │                     │
  claude_feature_*   ╰──●──●──●──●─────────╯
                        c1  c2  c3  c4
```

### 절차

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  1. 워크트리 생성 & 기능 브랜치 진입                            │
│     git worktree add wt_claude_feature_<설명>                   │
│     git checkout -b claude_feature_<설명>                       │
│                                                                 │
│  2. 작업 & 커밋                                                 │
│     ... 코드 수정 ...                                           │
│     git add <files>                                             │
│     git commit -m "설명"                                        │
│                                                                 │
│  ┌───────────────────────────────────────────────────────┐      │
│  │  3. ★ 사용자 확인 요청 ★                              │      │    
│  │     커밋 내용을 보고하고, 병합 진행 여부를 확인받는다 │      │
│  └───────────────────────────────────────────────────────┘      │
│                                                                 │
│  4. claude_develop에 병합 (승인 후)                             │
│     git checkout claude_develop                                 │
│     git merge --no-ff claude_feature_<설명>                     │
│                                                                 │
│  5. 정리                                                        │
│     git branch -d claude_feature_<설명>                         │
│     워크트리 제거                                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

> **주의**: 병합 완료 전에 워크트리를 제거하면 커밋이 유실됩니다.
> 반드시 **사용자 승인 → 병합 → 브랜치 삭제 → 워크트리 제거** 순서를 지킵니다.

## 3. 안정 병합 플로우

`claude_develop`의 변경사항을 `claude_main`으로 승격합니다.

```
  claude_main ━━━━━━━━━━━━━━━━━●━━━━━━━━━━━━━━━━━▶
                               ▲
                               │ merge --no-ff
                               │ (사용자 요청 시)
  claude_develop ━━●━━●━━●━━●━━●━━━━━━━━━━━━━━━━━▶
```

### 절차

```
┌─────────────────────────────────────────────────┐
│  (사용자 요청 확인)                             │
│                                                 │
│  1. git checkout claude_main                    │
│  2. git merge --no-ff claude_develop            │
│  3. git push origin claude_main                 │
│  4. git checkout claude_develop                 │
└─────────────────────────────────────────────────┘
```

## 4. 긴급 수정 (Hotfix) 플로우

`claude_main`에서 직접 분기하여 긴급 수정 후, **양쪽 브랜치에 모두 병합**합니다.

```
  claude_main ━━━━━━●━━━━━━━━━━━━━━━━●━━━━━━━━━━━▶
                    │                ▲
                    │ branch         │ merge --no-ff
                    │                │
  claude_hotfix     ╰──●──●──────────╯
                       c1  c2        │
                                     │ merge --no-ff
                                     ▼
  claude_develop ━━━━━━━━━━━━━━━━━━━━●━━━━━━━━━━━▶
```

### 절차

```
┌─────────────────────────────────────────────────────────────┐
│  1. git checkout -b claude_hotfix claude_main               │
│                                                             │
│  2. 수정 & 커밋                                             │
│                                                             │
│  ┌───────────────────────────────────────────────────┐      │
│  │  3. ★ 사용자 확인 요청 ★                          │      │
│  └───────────────────────────────────────────────────┘      │
│                                                             │
│  4. claude_main에 병합 (승인 후)                            │
│     git checkout claude_main                                │
│     git merge --no-ff claude_hotfix                         │
│                                                             │
│  5. claude_develop에도 병합                                 │
│     git checkout claude_develop                             │
│     git merge --no-ff claude_hotfix                         │
│                                                             │
│  6. 정리                                                    │
│     git branch -d claude_hotfix                             │
└─────────────────────────────────────────────────────────────┘
```

## 5. 릴리즈 플로우

`claude_main` → `main` 병합은 **사용자가 직접** 수행합니다.

```
  main ━━━━━━━━━━━━━━━━━━━━━━━━━━●━━━━━━━━━━━━━━━▶
                                 ▲
                                 │ merge --no-ff
                                 │ (사용자 직접 수행)
  claude_main ━━━━●━━━━●━━━━●━━━━●━━━━━━━━━━━━━━━▶
```

> Claude는 `main` 브랜치에 **절대** 직접 커밋하거나 푸시하지 않습니다.

## 6. 핵심 규칙 요약

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   1.  main 직접 커밋/푸시 ──────────── 절대 금지                │
│                                                                 │
│   2.  모든 병합 ───────────────────── --no-ff 필수              │
│                                                                 │
│   3.  파일 수정 작업 ──────────────── 워크트리 진입 후 수행     │
│                                                                 │
│   4.  병합 전 사용자 확인 ─────────── 커밋 후 반드시 승인 요청  │
│                                                                 │
│   5.  워크트리 제거 ───────────────── 병합 완료 후에만          │
│                                                                 │
│   6.  커밋 정리(squash/rebase) ────── 사용자 요청 시에만        │
│                                                                 │
│   7.  Git Identity ────────────────── 김은수 / eunsu.kim@...    │
│       (AI 에이전트 이름 절대 노출 금지)                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 7. 전체 흐름도

```
                          ┌──────────┐
                          │  릴리즈  │  사용자가 직접 수행
                          │  승인?   │◄─────────────────┐
                          └────┬─────┘                  │
                               │ Yes                    │
                               ▼                        │
  ┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓   │
  ┃  main                                           ┃───┘
  ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
                               ▲
                               │ merge --no-ff
  ┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
  ┃  claude_main               ●                    ┃◄──┐
  ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛   │
                ▲              ▲                        │
                │              │ merge --no-ff          │ hotfix
                │ hotfix       │ (사용자 요청)          │ merge
                │ branch       │                        │
  ┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓   │
  ┃  claude_develop            ●                    ┃───┘
  ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
                               ▲
                               │ merge --no-ff
                               │ (★ 사용자 승인 후 ★)
                               │
                ┌──────────────┴──────────────┐
                │                             │
  ┌─────────────────────┐    ┌─────────────────────┐
  │  claude_feature_A   │    │  claude_feature_B   │
  │  (작업 → 커밋)      │    │  (작업 → 커밋)      │
  └─────────────────────┘    └─────────────────────┘
```
